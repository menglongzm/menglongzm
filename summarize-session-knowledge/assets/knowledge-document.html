知识文档模板

本文示范独立可读的教学结构，以及 Mermaid、复杂图缩放、代码高亮、固定目录和主题切换的组合方式。

范围：这是可复用骨架。生成成品时删除所有占位说明、不需要的依赖和不适用章节。

1. 一句话定位

先说明本文解决什么学习问题、面向谁，以及哪些内容不在范围内。

2. 整体地图

下图回答：一个主题如何从输入经过处理到达可观察结果？图只表达主关系，具体边界由后文解释。

纯线性且一句话即可说明的内容应改用文字；这里只用于演示普通 Mermaid 图的渲染。

3. 核心知识

3.1 概念的主解释位置

每个规范概念只在一个位置完整解释。其他章节只补充新边界、引用主解释或在综合示例中使用。

3.2 复杂关系全景

下图回答：知识文档中的证据、主张、范围、章节、示例和验证记录如何关联？图的实体和字段较多，因此启用缩放拖拽。

图没有表达证据强弱和冲突裁决顺序，这些规则应继续用文字和表格精确说明。

4. 贯穿示例

代码示例必须自洽、标明语言，并转义来自会话或附件的 HTML 内容。
