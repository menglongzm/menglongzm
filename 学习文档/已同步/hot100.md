## 一、哈希 Hash

### 两数之和

**题目复述**

给定一个整数数组 `nums` 和目标值 `target`，需要在数组中找出两个不同下标 `i`、`j`，使得 `nums[i] + nums[j] == target`，并返回这两个下标。题目保证每组输入只对应一个答案，同一个元素不能重复使用。

**解答流程**

1. 创建哈希表 `map`，存储 `值 -> 下标`。
2. 从左到右遍历数组，当前值为 `nums[i]`。
3. 计算补数 `need = target - nums[i]`。
4. 如果 `need` 已经在哈希表中，说明找到答案，返回 `[map.get(need), i]`。
5. 否则把当前值和下标存入哈希表。

**注意事项**

- 必须先查补数，再放当前值，避免同一个元素被使用两次。
- 哈希表中保存的是下标，不是布尔值。
- 时间复杂度 `O(n)`，空间复杂度 `O(n)`。

### 字母异位词分组

**题目复述**

给定一个字符串数组 `strs`，需要把所有字母异位词分到同一组。字母异位词指由相同字母、相同出现次数组成，但排列顺序可以不同的字符串，例如 `"eat"`、`"tea"`、`"ate"`。

**解答流程**

1. 创建哈希表 `Map<String, List<String>>`。
2. 遍历每个字符串。
3. 为字符串生成唯一 key：
   - 方法一：把字符数组排序后转成字符串。
   - 方法二：统计 26 个字母出现次数，拼成频次 key。
4. 把原字符串加入对应 key 的列表。
5. 最后返回哈希表中的所有分组。

**注意事项**

- 排序 key 写法简单，复杂度约为 `O(n * k log k)`。
- 频次数组 key 更快，复杂度约为 `O(n * k)`。
- 频次 key 要加分隔符，例如 `1#0#2#`，避免 `[1,11]` 和 `[11,1]` 混淆。

### 最长连续序列

**题目复述**

给定一个未排序整数数组 `nums`，找出数字连续的最长序列长度。连续序列不要求在原数组中相邻，例如 `[100,4,200,1,3,2]` 中最长连续序列是 `[1,2,3,4]`，长度为 4。要求时间复杂度为 `O(n)`。

**解答流程**

1. 把所有数字放入 `HashSet`，同时完成去重。
2. 遍历 Set 中每个数字 `num`。
3. 只有当 `num - 1` 不在 Set 中时，才把 `num` 当作一个连续序列的起点。
4. 从 `num` 开始不断检查 `num + 1`、`num + 2` 是否存在。
5. 更新最长长度。

**注意事项**

- 关键优化是“只从起点开始数”，否则会退化成 `O(n^2)`。
- 遍历 Set 而不是原数组，可以避免重复数字干扰。
- 空数组返回 0。

## 二、双指针 Two Pointers

### 移动零

**题目复述**

给定数组 `nums`，将所有 `0` 移动到数组末尾，同时保持非零元素的相对顺序。要求原地操作，不能复制一个新数组。

**解答流程**

1. 使用慢指针 `slow` 表示下一个非零元素应该放的位置。
2. 使用快指针 `fast` 从左到右遍历数组。
3. 如果 `nums[fast] != 0`，就交换 `nums[slow]` 和 `nums[fast]`。
4. 交换后 `slow++`。

**注意事项**

- 如果 `slow == fast`，交换也没问题，只是自己和自己换。
- 这种写法能保持非零元素相对顺序。
- 也可以先覆盖非零元素，再把后面补零。

### 盛最多水的容器

**题目复述**

给定数组 `height`，每个元素表示一条竖线高度。任意两条竖线与 x 轴可以组成一个容器，容量为两线距离乘以较短高度。需要返回最大容量。

**解答流程**

1. 左指针 `left = 0`，右指针 `right = n - 1`。
2. 当前面积为 `(right - left) * min(height[left], height[right])`。
3. 更新最大面积。
4. 哪边高度更小，就移动哪边指针。
5. 重复直到左右指针相遇。

**注意事项**

- 面积由短板决定，所以移动高板没有意义。
- 每次移动短板，是为了尝试找到更高的短板。
- 不能用局部最高柱子贪心，会漏解。

### 三数之和

**题目复述**

给定整数数组 `nums`，找出所有不重复三元组 `[a,b,c]`，使得 `a + b + c == 0`。三元组中的元素来自不同下标，答案中不能包含重复三元组。

**解答流程**

1. 先对数组排序。
2. 外层循环固定第一个数 `nums[i]`。
3. 如果 `i > 0` 且 `nums[i] == nums[i - 1]`，跳过，避免重复。
4. 内层使用左右指针：`left = i + 1`，`right = n - 1`。
5. 计算三数之和：
   - 等于 0：加入答案，并跳过左右重复值。
   - 小于 0：`left++`。
   - 大于 0：`right--`。

**注意事项**

- 排序是去重和双指针的前提。
- 固定数要去重，左右指针找到答案后也要去重。
- 如果 `nums[i] > 0`，后面都大于 0，可以直接结束。

### 接雨水

**题目复述**

给定非负整数数组 `height` 表示柱子高度，每根柱子宽度为 1。下雨后，柱子之间可以积水，要求计算总接水量。

**解答流程**

双指针写法：

1. 左指针 `left`，右指针 `right`。
2. 维护左侧最高柱 `leftMax` 和右侧最高柱 `rightMax`。
3. 如果 `height[left] < height[right]`，左侧当前能接多少水只由 `leftMax` 决定。
4. 否则右侧当前能接多少水只由 `rightMax` 决定。
5. 每次处理较矮一侧并移动对应指针。

**注意事项**

- 某一列能接水量为 `min(左侧最高, 右侧最高) - 当前高度`。
- 双指针的关键是：较矮侧的上限已经确定。
- 单调栈也能做，但边界更绕。

## 三、滑动窗口 Sliding Window

### 无重复字符的最长子串

**题目复述**

给定字符串 `s`，找出不含重复字符的最长连续子串长度。注意是子串，必须连续。

**解答流程**

1. 使用哈希表记录每个字符最后一次出现的位置。
2. 左边界 `left = 0`。
3. 右指针遍历字符串。
4. 如果当前字符之前出现过，并且位置在当前窗口内，则更新 `left = 上次位置 + 1`。
5. 每次更新答案 `right - left + 1`。

**注意事项**

- 左边界只能向右移动，要写 `left = Math.max(left, lastIndex + 1)`。
- 不能把子序列和子串混淆。
- 如果字符范围较小，可以用数组代替 HashMap。

### 找到字符串中所有字母异位词

**题目复述**

给定字符串 `s` 和 `p`，找出 `s` 中所有是 `p` 的字母异位词的连续子串，并返回这些子串的起始下标。

**解答流程**

1. 窗口大小固定为 `p.length()`。
2. 用两个长度为 26 的数组记录 `p` 的字符频次和当前窗口频次。
3. 初始化第一个窗口。
4. 每次判断两个频次数组是否相等。
5. 窗口右移时，加入右侧新字符，移除左侧旧字符。

**注意事项**

- 窗口大小必须固定。
- 比较频次数组可以用 `Arrays.equals`。
- 注意 `s.length() < p.length()` 时直接返回空列表。

## 四、子串 / 前缀和 / 队列

### 和为 K 的子数组

**题目复述**

给定整数数组 `nums` 和整数 `k`，统计数组中和为 `k` 的连续非空子数组数量。数组中可能有负数。

**解答流程**

1. 使用前缀和 `sum` 表示从开头到当前位置的累加和。
2. 用哈希表记录每种前缀和出现次数。
3. 初始化 `map.put(0, 1)`，表示空前缀出现一次。
4. 遍历数组，更新 `sum += nums[i]`。
5. 如果 `sum - k` 出现过，说明存在若干子数组以当前位置结尾且和为 `k`。
6. 累加次数后，把当前 `sum` 加入哈希表。

**注意事项**

- 不能用普通滑动窗口，因为有负数时窗口和不具备单调性。
- 必须先查 `sum - k`，再记录当前 `sum`。
- `map.put(0, 1)` 很关键，用于处理从下标 0 开始的子数组。

---

### 滑动窗口最大值

**题目复述**

给定数组 `nums` 和窗口大小 `k`，窗口从左到右滑动，每次返回当前窗口中的最大值。

**解答流程**

1. 使用双端队列 `Deque<Integer>`，队列中存下标。
2. 队列对应的值保持单调递减。
3. 遍历每个下标 `i`：
   - 如果队头下标已经滑出窗口，移除。
   - 当队尾元素小于等于当前值时，不可能再成为最大值，移除。
   - 当前下标入队。
4. 当 `i >= k - 1` 时，队头就是当前窗口最大值下标。

**注意事项**

- 队列存下标，不存值，方便判断是否过期。
- 维护单调递减，队头最大。
- 移除队尾时通常用 `<=`，可以去掉旧的相同值。

### 最小覆盖子串

**题目复述**

给定字符串 `s` 和 `t`，找出 `s` 中最短的连续子串，使它包含 `t` 中所有字符以及对应出现次数。如果不存在，返回空字符串。

**解答流程**

1. 用哈希表或数组统计 `t` 中每个字符需要的次数。
2. 右指针扩张窗口，加入字符并更新窗口计数。
3. 当窗口已经覆盖 `t` 时，尝试移动左指针收缩窗口。
4. 每次窗口达标时更新最短答案。
5. 收缩到不达标后，继续右扩。

**注意事项**

- “包含所有字符”包含次数，例如 `t = "AABC"` 需要两个 `A`。
- 需要维护一个 `valid` 或 `count` 判断窗口是否达标。
- 更新答案要在窗口达标时做。

## 五、普通数组 Array

### 最大子数组和

**题目复述**

给定整数数组 `nums`，找出一个和最大的连续子数组，返回最大和。子数组至少包含一个元素。

**解答流程**

1. 维护 `cur` 表示以当前位置结尾的最大子数组和。
2. 对每个数 `x`，状态转移为 `cur = max(x, cur + x)`。
3. 用 `ans` 记录过程中出现过的最大 `cur`。

**注意事项**

- 如果数组全是负数，答案是最大的那个负数，所以不能简单初始化答案为 0。
- `cur < 0` 时可以丢弃前面的累加和。
- 本质是动态规划，也可以理解为贪心。

### 合并区间

**题目复述**

给定若干区间 `intervals`，合并所有重叠区间，并返回互不重叠的区间集合。

**解答流程**

1. 按区间左端点升序排序。
2. 遍历排序后的区间。
3. 如果结果集为空，直接加入。
4. 否则比较当前区间左端点和结果集中最后一个区间右端点：
   - 如果当前左端点小于等于最后右端点，说明重叠，更新右端点。
   - 否则加入新区间。

**注意事项**

- 排序是核心前提。
- 合并时右端点取最大值。
- Java 排序比较器建议写 `Integer.compare(a[0], b[0])`，避免减法溢出。

### 轮转数组

**题目复述**

给定数组 `nums`，将数组元素向右轮转 `k` 个位置。要求尝试使用 `O(1)` 额外空间原地完成。

**解答流程**

三次反转：

1. 令 `k = k % n`。
2. 反转整个数组。
3. 反转前 `k` 个元素。
4. 反转后 `n - k` 个元素。

**注意事项**

- 一定要先取模，否则 `k` 可能大于数组长度。
- 右轮转和左轮转的反转顺序不同。
- 手写 `reverse(nums, l, r)` 时注意双指针边界。

### 除自身以外数组的乘积

**题目复述**

给定整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于除 `nums[i]` 之外所有元素的乘积。不能使用除法，要求 `O(n)` 时间。

**解答流程**

1. 创建答案数组 `ans`。
2. 正向遍历，令 `ans[i]` 先保存 `i` 左侧所有元素乘积。
3. 反向遍历，用变量 `right` 保存 `i` 右侧所有元素乘积。
4. 每次令 `ans[i] *= right`。
5. 更新 `right *= nums[i]`。

**注意事项**

- 输出数组不算额外空间时，可以做到 `O(1)` 额外空间。
- 不要用除法，因为数组中可能有 0。
- 初始化左积和右积都应该是 1。

### 缺失的第一个正数

**题目复述**

给定一个未排序整数数组 `nums`，找出没有出现的最小正整数。要求时间复杂度 `O(n)`，额外空间复杂度 `O(1)`。

**解答流程**

1. 对长度为 `n` 的数组，答案只可能在 `[1, n + 1]`。
2. 遍历数组，把值 `x` 放到下标 `x - 1` 的位置。
3. 只处理 `1 <= x <= n` 的数字。
4. 通过 while 不断交换，直到当前位置的数字无法继续放置。
5. 最后再遍历数组，第一个 `nums[i] != i + 1` 的位置，答案是 `i + 1`。
6. 如果全部匹配，答案是 `n + 1`。

**注意事项**

- 交换条件中要避免死循环：`nums[i] != nums[nums[i] - 1]`。
- 负数、0、大于 n 的数都不用管。
- 这是原地哈希，利用数组下标表达数字是否出现。

## 六、矩阵 Matrix

### 矩阵置零

**题目复述**

给定 `m x n` 矩阵，如果某个元素为 0，则将它所在的整行和整列都置为 0。要求尽量原地完成。

**解答流程**

1. 先用两个布尔变量记录第一行、第一列原本是否有 0。
2. 遍历非第一行第一列区域。
3. 如果 `matrix[i][j] == 0`，就标记 `matrix[i][0] = 0` 和 `matrix[0][j] = 0`。
4. 再遍历非第一行第一列，根据标记置零。
5. 最后根据布尔变量处理第一行和第一列。

**注意事项**

- 第一行第一列既保存原始数据，又作为标记位，所以必须额外记录它们原本是否有 0。
- 处理第一行第一列要放在最后。



---

**方法二：使用额外标记数组 (Using Extra Arrays)**

**解答流程**

1.  **创建标记数组**：
    *   创建两个布尔数组：`rowFlags`（长度为 $m$）和 `colFlags`（长度为 $n$）。
    *   初始值全部设为 `false`。
2.  **第一次遍历（记录零的位置）**：
    *   遍历整个矩阵。如果发现 `matrix[i][j] == 0`：
        *   将 `rowFlags[i]` 标记为 `true`。
        *   将 `colFlags[j]` 标记为 `true`。
3.  **第二次遍历（执行置零）**：
    *   再次遍历整个矩阵。对于任意位置 `(i, j)`：
        *   如果 `rowFlags[i]` 为 `true` **或者** `colFlags[j]` 为 `true`。
        *   则执行 `matrix[i][j] = 0`。

**代码逻辑示例 (Java)**
```java
int m = matrix.length, n = matrix[0].length;
boolean[] rowFlags = new boolean[m];
boolean[] colFlags = new boolean[n];

// 记录哪些行、哪些列需要置零
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        if (matrix[i][j] == 0) {
            rowFlags[i] = true;
            colFlags[j] = true;
        }
    }
}

// 根据标记进行置零
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        if (rowFlags[i] || colFlags[j]) {
            matrix[i][j] = 0;
        }
    }
}
```

**注意事项**

*   **空间换简单性**：相比于利用第一行第一列做标记的方法，该方法不需要处理“第一行/列标记位被覆盖”的复杂逻辑。
*   **适用场景**：当矩阵尺寸较小，或者对 $O(m+n)$ 的空间开销不敏感时，此方法代码更易维护且不容易出错。

**复杂度分析**
*   **时间复杂度**：$O(m \times n)$，需要两次完整的矩阵遍历。
*   **空间复杂度**：$O(m + n)$，需要两个额外数组来存储行和列的置零状态。

### 螺旋矩阵

**题目复述**

给定 `m x n` 矩阵，按照顺时针螺旋顺序返回矩阵中的所有元素。

**解答流程**

1. 定义四个边界：`top`、`bottom`、`left`、`right`。
2. 从左到右遍历上边界，然后 `top++`。
3. 从上到下遍历右边界，然后 `right--`。
4. 如果 `top <= bottom`，从右到左遍历下边界，然后 `bottom--`。
5. 如果 `left <= right`，从下到上遍历左边界，然后 `left++`。
6. 重复直到边界交错。

**注意事项**

- 遍历下边和左边前要重新检查边界，避免单行或单列重复加入。
- 四个边界每走完一条边就要收缩。

---

---


**解答流程（四边界收缩法）**

1.  **定义边界**：设置上边界 `u=0`，下边界 `d=m-1`，左边界 `l=0`，右边界 `r=n-1`。
2.  **循环遍历**：使用 `while(true)` 开启循环，按“右、下、左、上”的顺序收缩：
    *   **从左到右**：遍历 `l` 到 `r`，加入结果。然后 `u++`（上边界下移），若 `u > d` 则退出。
    *   **从上到下**：遍历 `u` 到 `d`，加入结果。然后 `r--`（右边界左移），若 `r < l` 则退出。
    *   **从右到左**：遍历 `r` 到 `l`，加入结果。然后 `d--`（下边界上移），若 `d < u` 则退出。
    *   **从下到上**：遍历 `d` 到 `u`，加入结果。然后 `l++`（左边界右移），若 `l > r` 则退出。

**代码逻辑示例 (Java)**

```java
int u = 0, d = m - 1, l = 0, r = n - 1;
while(true){
    // 1. 从左向右
    for(int i = l; i <= r; i++) ans.add(matrix[u][i]);
    if(++u > d) break;
    
    // 2. 从上向下
    for(int i = u; i <= d; i++) ans.add(matrix[i][r]);
    if(--r < l) break;
    
    // 3. 从右向左
    for(int i = r; i >= l; i--) ans.add(matrix[d][i]);
    if(--d < u) break;
    
    // 4. 从下向上
    for(int i = d; i >= u; i--) ans.add(matrix[i][l]);
    if(++l > r) break;
}
```

**注意事项**

*   **即时检查**：每一条边遍历完后，必须立即通过 `if` 判断边界并 `break`。这样可以防止在处理非方阵（如单行或单列矩阵）时出现重复遍历。
*   **边界定义**：四个边界变量分别代表了当前尚未被遍历的区域范围。
*   **循环结束条件**：当任意一对边界（上下或左右）交错时，说明所有元素已遍历完毕。

**复杂度分析**
*   **时间复杂度**：$O(m \times n)$，其中 $m$ 和 $n$ 分别是矩阵的行数和列数。矩阵中的每个元素都被访问且只访问一次。
*   **空间复杂度**：$O(1)$。除了输出列表外，仅使用了常数个额外变量。

### 搜索二维矩阵 II

**题目复述**

**解答流程**

1. 从右上角开始，位置为 `(0, n - 1)`。
2. 如果当前值等于 target，返回 true。
3. 如果当前值大于 target，说明当前列下面都更大，向左移动。
4. 如果当前值小于 target，说明当前行左边都更小，向下移动。
5. 越界后返回 false。

**注意事项**

- 右上角和左下角都可以作为起点。
- 从左上角或右下角无法一次排除一整行或一整列。
- 时间复杂度 `O(m + n)`。

## 七、链表 Linked List

### 相交链表

**题目复述**

给定两个单链表的头节点 `headA` 和 `headB`，判断它们是否相交。如果相交，返回相交的第一个节点；如果不相交，返回 null。相交指两个链表从某个节点开始共享同一批节点对象。

**解答流程**

1. 指针 `pA` 从 `headA` 出发，`pB` 从 `headB` 出发。
2. `pA` 走到 null 后转到 `headB`。
3. `pB` 走到 null 后转到 `headA`。
4. 两个指针每次都走一步。
5. 如果相交，会在交点相遇；不相交会同时变成 null。

**注意事项**

- 比较节点是否相同要用引用比较 `pA == pB`。
- 不是比较节点值是否相等。
- 两个指针都走了 `A长度 + B长度`，长度差被抵消。

### 反转链表

**题目复述**

给定单链表头节点 `head`，将链表反转，并返回反转后的新头节点。

**解答流程**

1. 初始化 `prev = null`，`cur = head`。
2. 当 `cur != null`：
   - 保存 `next = cur.next`。
   - 令 `cur.next = prev`。
   - `prev = cur`。
   - `cur = next`。
3. 返回 `prev`。

**注意事项**

- 一定要先保存 `next`，否则链表断开后找不到后续节点。
- 最终 `prev` 是新头节点。

### 回文链表

**题目复述**

给定单链表头节点，判断链表从前往后和从后往前读是否相同。

**解答流程**

1. 使用快慢指针找到链表中点。
2. 反转后半段链表。
3. 用两个指针分别从头部和后半段头部开始比较。
4. 如果全部相等，返回 true，否则 false。

**注意事项**

- 奇数长度链表中间节点不用比较。
- 面试中可以选择最后恢复链表结构。
- 比较的是节点值，不是节点对象。
- 中点写法要和后续反转逻辑配套：
  - `fast = head, slow = head`，循环条件 `fast != null && fast.next != null`，偶数长度时 `slow` 停在上中点。
  - `fast = dummy, slow = dummy` 或 `fast = head.next, slow = head`，常用于让 `slow` 停在前半段尾部，再反转 `slow.next`。
- 反转后半段时要返回反转后的新头节点，例如 `slow.next = reverse(slow.next)`，不能只在反转函数里改局部变量。

### 环形链表

**题目复述**

给定单链表头节点，判断链表中是否存在环。存在环表示某个节点的 `next` 指针指向了前面已经出现过的节点。

**解答流程**

1. 慢指针一次走一步，快指针一次走两步。
2. 如果快指针或 `fast.next` 为 null，说明无环。
3. 如果快慢指针相遇，说明有环。

**注意事项**

- 循环条件要写 `fast != null && fast.next != null`。
- 有环时快指针一定会追上慢指针。

### 环形链表 II

**题目复述**

给定单链表头节点，如果链表有环，返回入环的第一个节点；如果无环，返回 null。

**解答流程**

1. 先用快慢指针判断是否有环。
2. 如果快慢指针相遇，令其中一个指针回到头节点。
3. 两个指针都改为一次走一步。
4. 再次相遇的位置就是入环点。

**注意事项**

- 第一阶段快指针一次两步，慢指针一次一步。
- 第二阶段两个指针都必须一次一步。
- 返回的是节点对象，不是下标或值。

### 合并两个有序链表

**题目复述**

给定两个升序链表 `list1` 和 `list2`，把它们合并成一个新的升序链表，并返回合并后链表头节点。新链表由原链表节点拼接而成。

**解答流程**

1. 创建虚拟头节点 `dummy`。
2. 使用 `cur` 指向新链表尾部。
3. 比较两个链表当前节点值。
4. 谁更小，就接到 `cur.next` 后面，并移动对应链表指针。
5. 移动 `cur`。
6. 循环结束后接上剩余链表。
7. 返回 `dummy.next`。

**注意事项**

- dummy 节点可以统一处理头节点变化。
- 最后剩余链表可以整段接上，不需要逐个节点处理。

### 两数相加

**题目复述**

给定两个非空链表，分别表示两个非负整数。数字按逆序存储，每个节点存一位数字。需要把两个数相加，并以相同形式返回结果链表。

**解答流程**

1. 创建 dummy 节点和当前指针 `cur`。
2. 维护进位 `carry`。
3. 当 `l1`、`l2` 或 `carry` 任一存在时继续循环。
4. 当前和为 `x + y + carry`。
5. 新节点值为 `sum % 10`。
6. 新进位为 `sum / 10`。
7. 移动链表指针。

**注意事项**

- 两个链表长度可能不同。
- 最后如果还有进位，要新建节点。
- 数字逆序存储，所以可以从头开始直接加。

### 删除链表的倒数第 N 个结点

**题目复述**

给定链表头节点和整数 `n`，删除链表倒数第 `n` 个节点，并返回删除后的头节点。

**解答流程**

1. 创建 dummy 节点，`dummy.next = head`。
2. 设置快慢指针都从 dummy 出发。
3. 快指针先走 `n` 步。
4. 快慢指针一起走，直到快指针到达最后一个节点。
5. 此时慢指针在待删除节点前一个位置。
6. 执行 `slow.next = slow.next.next`。
7. 返回 `dummy.next`。

**注意事项**

- dummy 可以处理删除头节点的情况。
- 也有写法让快指针先走 `n + 1` 步，然后走到 null，注意模板要统一。

### 两两交换链表中的节点

**题目复述**

给定链表头节点，两两交换相邻节点，并返回交换后的链表头。不能只交换节点值，必须改变节点连接关系。

**解答流程**

1. 创建 dummy 节点指向 head。
2. `prev` 指向每组两个节点之前的节点。
3. 当 `prev.next` 和 `prev.next.next` 都不为空时：
   - `node1 = prev.next`
   - `node2 = node1.next`
   - 调整指针：`prev.next = node2`，`node1.next = node2.next`，`node2.next = node1`
4. `prev = node1`，进入下一组。

**注意事项**

- 修改指针顺序很重要，先保存两个节点。
- 不能通过交换值取巧。
- 奇数个节点时最后一个不动。

### K 个一组翻转链表

**题目复述**

给定链表头节点，每 `k` 个节点一组进行翻转。如果最后不足 `k` 个节点，则保持原样。需要返回翻转后的链表头。

**解答流程**

1. 使用 dummy 节点。
2. 每次从 `groupPrev` 开始向后找第 `k` 个节点。
3. 如果不足 `k` 个，结束。
4. 记录下一组起点 `groupNext`。
5. 翻转当前 `[groupPrev.next, kth]` 这一段。
6. 把翻转后的头尾和前后链表重新连接。
7. `groupPrev` 移到本组翻转后的尾部。

**注意事项**

- 不足 `k` 个不能翻转。
- 翻转局部链表前要保存下一组起点。
- 这是反转链表的升级版，难点在分组连接。

### 随机链表的复制

**题目复述**

给定一个链表，每个节点除了 `next` 指针外，还有一个 `random` 指针，可能指向任意节点或 null。要求构造该链表的深拷贝，新链表节点不能复用原节点。

**解答流程**

原地拼接法：

1. 在每个原节点后面插入它的拷贝节点。
2. 复制 random：如果 `cur.random != null`，则 `cur.next.random = cur.random.next`。
3. 拆分链表，把原链表恢复，同时抽出拷贝链表。

**注意事项**

- 深拷贝要求所有节点都是新对象。
- `random` 为空时要单独判断。
- 也可以用 HashMap 记录 `原节点 -> 新节点`，更直观但空间为 `O(n)`。


**方法二：哈希映射法 (HashMap Approach)** 

**解答流程**

1.  **建立映射关系**：
    *   遍历原链表，为每个原节点创建一个对应的新节点（仅复制值 `val`）。
    *   使用 `HashMap` 存储映射关系：`Key` 为原节点，`Value` 为新创建的拷贝节点。
2.  **构建新链表结构**：
    *   再次遍历原链表。
    *   利用 Map 获取当前原节点对应的拷贝节点：`copyNode = map.get(cur)`。
    *   **设置指针**：
        *   `copyNode.next = map.get(cur.next)`
        *   `copyNode.random = map.get(cur.random)`
3.  **返回结果**：返回 `map.get(head)` 即可。

**代码逻辑示例 (Java)**
```java
Map<Node, Node> map = new HashMap<>();
Node cur = head;
// 第一遍遍历：建立原节点 -> 新节点的映射
while (cur != null) {
    map.put(cur, new Node(cur.val));
    cur = cur.next;
}
cur = head;
// 第二遍遍历：根据原链表的连接关系，设置新节点的指针
while (cur != null) {
    map.get(cur).next = map.get(cur.next);
    map.get(cur).random = map.get(cur.random);
    cur = cur.next;
}
return map.get(head);
```

**注意事项**

*   **空间换时间**：该方法逻辑最直观，但需要额外的 $O(n)$ 空间来存储哈希表。
*   **处理 null**：由于 `map.get(null)` 会返回 `null`，因此在设置 `next` 和 `random` 指针时，如果原节点指向空，拷贝节点也会正确地指向空，无需额外判空逻辑（取决于编程语言的 Map 实现，Java 中 `map.get(null)` 默认处理良好）。
*   **深拷贝验证**：确保新链表的所有 `next` 和 `random` 指向的都是 Map 中的新对象，而非原链表的对象。

**复杂度分析**
*   **时间复杂度**：$O(n)$，两次遍历链表。
*   **空间复杂度**：$O(n)$，哈希表存储 $n$ 个节点的映射关系。

--- 

这种方法相比“原地拼接法”更容易在面试中快速写出且不容易出错，但在追求 $O(1)$ 额外空间复杂度时，原地法更优。

### 排序链表

**题目复述**

给定单链表头节点 `head`，请将链表按升序排序，并返回排序后的链表。要求时间复杂度尽量做到 `O(n log n)`，进阶要求常数级额外空间。

**解答流程**

递归归并排序：

1. 如果链表为空或只有一个节点，直接返回。
2. 使用快慢指针找到前半段尾节点。
3. 令 `right = slow.next`，再执行 `slow.next = null`，把链表断成两段。
4. 递归排序左半段和右半段。
5. 合并两个有序链表并返回。

核心代码：

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) return head;

        ListNode slow = head, fast = head.next;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        ListNode right = slow.next;
        slow.next = null;

        ListNode left = sortList(head);
        right = sortList(right);

        return merge(left, right);
    }

    private ListNode merge(ListNode a, ListNode b) {
        ListNode dummy = new ListNode(-1);
        ListNode cur = dummy;

        while (a != null && b != null) {
            if (a.val <= b.val) {
                cur.next = a;
                a = a.next;
            } else {
                cur.next = b;
                b = b.next;
            }
            cur = cur.next;
        }

        cur.next = a != null ? a : b;
        return dummy.next;
    }
}
```

**注意事项**

- `fast = head.next` 可以让 `slow` 停在前半段尾部，方便断链。
- 断链 `slow.next = null` 必不可少，否则递归无法缩小问题。
- 合并剩余链表时要写 `cur.next = left` 或 `cur.next = right`，不是 `cur = left`。
- 递归版空间复杂度是 `O(log n)`；严格 `O(1)` 额外空间要用自底向上的迭代归并。

## 八、二叉树 Binary Tree

### 二叉树的中序遍历

**题目复述**

给定二叉树根节点 `root`，返回它的中序遍历结果。中序遍历顺序为：左子树、根节点、右子树。

**解答流程**

递归：

1. 如果节点为空，返回。
2. 递归遍历左子树。
3. 访问当前节点。
4. 递归遍历右子树。

迭代：

1. 使用栈。
2. 当前节点不为空时一路向左压栈。
3. 弹出节点并访问。
4. 转向右子树。

**注意事项**

- BST 的中序遍历是严格递增序列，这是很多 BST 题的基础。
- 迭代写法中，外层条件是 `cur != null || !stack.isEmpty()`。

### 二叉树的最大深度

**题目复述**

给定二叉树根节点，返回最大深度。最大深度是从根节点到最远叶子节点路径上的节点数。

**解答流程**

1. 如果当前节点为空，深度为 0。
2. 递归求左子树深度。
3. 递归求右子树深度。
4. 当前深度为 `max(left, right) + 1`。

**注意事项**

- 返回的是节点数，不是边数。
- 这类题是典型后序遍历：先拿到左右子树结果，再计算当前节点。

### 翻转二叉树

**题目复述**

给定二叉树根节点，翻转整棵树，即交换每个节点的左右子树，并返回翻转后的根节点。

**解答流程**

1. 如果节点为空，返回 null。
2. 交换当前节点的 `left` 和 `right`。
3. 递归翻转左子树。
4. 递归翻转右子树。
5. 返回根节点。

**注意事项**

- 前序、后序、层序都能做。
- 中序也能做，但交换后递归方向容易混乱，初学不推荐。

### 对称二叉树

**题目复述**

给定二叉树根节点，判断这棵树是否关于中心轴镜像对称。

**解答流程**

1. 写辅助函数 `check(left, right)`。
2. 如果两个节点都为空，返回 true。
3. 如果只有一个为空，返回 false。
4. 如果两个节点值不同，返回 false。
5. 递归比较：
   - `left.left` 和 `right.right`
   - `left.right` 和 `right.left`

**注意事项**

- 比较的是两棵子树是否镜像，不是单棵树自己左右是否相等。
- 层序也能做，但递归更直观。

### 二叉树的直径

**题目复述**

给定二叉树，返回任意两个节点之间最长路径的长度。路径长度按边数计算，这条路径可以经过根节点，也可以不经过根节点。

**解答流程**

1. 使用后序遍历求每个节点的最大深度。
2. 对每个节点，经过它的最长路径为 `左深度 + 右深度`。
3. 用全局变量 `ans` 维护最大直径。
4. 当前节点向父节点返回 `max(leftDepth, rightDepth) + 1`。

**注意事项**

- 直径是边数，`leftDepth + rightDepth` 正好是经过当前节点的边数。
- 最大路径不一定经过根节点，所以必须遍历每个节点。

---

### 二叉树的层序遍历

**题目复述**

给定二叉树根节点，按层从左到右返回节点值，每一层单独作为一个列表。

**解答流程**

1. 如果根节点为空，返回空列表。
2. 根节点入队。
3. 当队列不为空时，先记录当前层节点数量 `size`。
4. 循环 `size` 次，依次出队并加入当前层列表。
5. 把出队节点的左右孩子入队。
6. 当前层处理完后加入答案。

**注意事项**

- 每层开始前一定要固定 `size`，否则会把下一层节点混进当前层。
- BFS 使用 `Queue<TreeNode>`。

### 将有序数组转换为二叉搜索树

**题目复述**

给定升序整数数组 `nums`，将其转换为一棵高度平衡的二叉搜索树。高度平衡指每个节点左右子树高度差不超过 1。

**解答流程**

1. 使用递归处理区间 `[l, r]`。

3. 取中点 `mid` 作为根节点。
4. 左半区间构建左子树。
5. 右半区间构建右子树。
6. 返回根节点。

**注意事项**

- 取中点是为了保证平衡。
- 写中点建议 `mid = l + (r - l) / 2`。
- 左右区间不要包含 `mid`，否则死递归。

### 验证二叉搜索树

**题目复述**

给定二叉树根节点，判断它是否是有效二叉搜索树。有效 BST 要求每个节点左子树所有值都小于当前节点，右子树所有值都大于当前节点，并且左右子树也必须是 BST。

**解答流程**

中序写法：

1. 对树做中序遍历。
2. 维护上一个访问节点值 `pre`。
3. 如果当前值 `<= pre`，说明不是严格递增，返回 false。
4. 遍历结束仍合法，则返回 true。

上下界写法：

1. 每个节点都有合法范围 `(low, high)`。
2. 当前值必须满足 `low < val < high`。
3. 左子树上界变成当前值，右子树下界变成当前值。

**注意事项**

- BST 要求严格小于和严格大于，不能有重复值。
- 上下界建议用 `long`，避免节点值等于 `Integer.MIN_VALUE` 或 `Integer.MAX_VALUE` 时出错。

### 二叉搜索树中第 K 小的元素

**题目复述**

给定二叉搜索树根节点和整数 `k`，返回树中第 `k` 小的节点值。

**解答流程**

1. 利用 BST 中序遍历递增的性质。
2. 按中序遍历访问节点。
3. 每访问一个节点，计数器 `count++`。
4. 当 `count == k` 时，当前节点就是答案。

**注意事项**

- 可以递归，也可以栈迭代。
- 找到答案后可以提前结束，避免无意义遍历。
- `k` 从 1 开始，不是从 0 开始。

### 二叉树的右视图

**题目复述**

给定一棵二叉树的根节点 `root`，想象自己站在这棵树的右侧，从上到下观察它。请返回从右侧能够看到的节点值。也就是说，每一层只返回最右边那个能被看到的节点。

**解答流程**

层序遍历写法：

1. 如果根节点为空，返回空列表。
2. 使用队列进行 BFS，把根节点加入队列。
3. 每一轮先记录当前层节点数量 `size`。
4. 循环处理当前层的 `size` 个节点。
5. 当处理到当前层最后一个节点时，把它的值加入答案。
6. 将当前节点的左右子节点加入队列。
7. 所有层处理完后返回答案。

DFS 写法：

1. 按照 `根 -> 右 -> 左` 的顺序递归。
2. 用 `depth` 表示当前深度。
3. 如果 `depth == ans.size()`，说明第一次到达这一层，此时看到的一定是最右节点。
4. 将当前节点值加入答案。

**注意事项**

- 层序遍历时，每层只加入最后一个节点。
- DFS 时必须先访问右子树，再访问左子树。
- 右视图不是只沿着右指针走，某些层的右视图节点可能来自左子树。

### 二叉树展开为链表

**题目复述**

给定二叉树根节点 `root`，请将它原地展开为一个单链表。展开后的链表仍然使用树节点的 `right` 指针指向下一个节点，`left` 指针全部置为 `null`。展开顺序要求与二叉树的前序遍历顺序一致。

**解答流程**

递归后序写法：

1. 递归展开左子树。
2. 递归展开右子树。
3. 保存原来的右子树 `rightSubtree`。
4. 将左子树移动到右子树位置：`root.right = root.left`。
5. 将 `root.left = null`。
6. 沿着新的右链走到末尾。
7. 把原来的右子树接到末尾。

前序辅助列表写法：

1. 先前序遍历，把所有节点按顺序放入列表。
2. 再遍历列表，依次修改每个节点的 `left` 和 `right` 指针。

**注意事项**

- 题目要求原地展开，最好掌握不额外存列表的写法。
- 展开顺序是前序遍历：根、左、右。
- 修改指针前要先保存原右子树，否则会丢失节点。
- 展开后所有 `left` 都必须为 `null`。

### 从前序与中序遍历序列构造二叉树

**题目复述**

给定一棵二叉树的前序遍历数组 `preorder` 和中序遍历数组 `inorder`，其中树中没有重复元素。请根据这两个遍历序列还原并返回原二叉树。

**解答流程**

1. 前序遍历的第一个元素一定是当前子树根节点。
2. 在中序遍历中找到根节点位置。
3. 中序中根节点左边是左子树，右边是右子树。
4. 根据左子树长度，切分前序遍历中的左右子树范围。
5. 递归构建左子树和右子树。
6. 返回根节点。

优化写法：

1. 先用 HashMap 记录 `中序值 -> 下标`。
2. 递归时传数组边界，不要频繁复制数组。
3. 通过中序下标快速定位根节点。

**注意事项**

- 前序确定根，中序确定左右子树范围。
- 题目说明节点值不重复，所以可以用 HashMap 快速定位。
- 递归边界要统一，常用闭区间 `[l, r]`。
- 不要在每层递归中创建新数组，否则空间和时间开销会变大。

### 路径总和 III

**题目复述**

给定一棵二叉树的根节点 `root` 和整数 `targetSum`。路径不需要从根节点开始，也不需要在叶子节点结束，但必须沿着父节点到子节点的方向向下。请返回路径和等于 `targetSum` 的路径数量。

**解答流程**

前缀和写法：

1. 从根节点开始 DFS，维护从根到当前节点的路径前缀和 `curSum`。
2. 如果存在之前的前缀和 `curSum - targetSum`，说明从那个位置之后到当前节点的路径和为 target。
3. 使用 HashMap 记录每个前缀和出现次数。
4. 进入当前节点时，把当前前缀和加入 map。
5. 递归遍历左右子树。
6. 回溯离开当前节点时，把当前前缀和次数减 1。

**注意事项**

- 路径必须向下，不能从子节点走回父节点。
- 初始化 `map.put(0L, 1)`，用于统计从根节点开始的合法路径。
- 节点值可能较大，前缀和建议用 `long`。
- 回溯时必须撤销当前前缀和，否则会影响其他分支。

补充：枚举起点写法也可以做。

1. 外层 DFS 枚举每个节点作为路径起点。
2. 内层 DFS 从该起点向下累加路径和。
3. 每到一个节点，先把当前节点值加入路径和，再判断是否等于 `targetSum`。
4. 内层 DFS 建议直接返回满足条件的路径数量，不要试图用 `int ans` 参数带回结果。

核心代码：

```java
public int pathSum(TreeNode root, int targetSum) {
    if (root == null) return 0;
    return countFrom(root, targetSum, 0L)
         + pathSum(root.left, targetSum)
         + pathSum(root.right, targetSum);
}

private int countFrom(TreeNode node, int targetSum, long sum) {
    if (node == null) return 0;

    sum += node.val;
    int ans = sum == targetSum ? 1 : 0;

    ans += countFrom(node.left, targetSum, sum);
    ans += countFrom(node.right, targetSum, sum);
    return ans;
}
```

状态恢复要看状态类型：

- `long sum` 是基本类型，每层递归拿到的是自己的副本，不需要手动 `sum -= node.val`。
- `List path`、`Map prefixSum` 这类共享对象会被左右子树共用，递归结束时必须恢复。

### 二叉树的最近公共祖先

**题目复述**

给定一棵普通二叉树的根节点 `root`，以及树中的两个节点 `p` 和 `q`。请返回它们的最近公共祖先。最近公共祖先是指同时拥有 `p` 和 `q` 作为后代的最深节点，一个节点也可以是它自己的后代。

**解答流程**

1. 如果当前节点为空，返回 null。
2. 如果当前节点等于 `p` 或 `q`，直接返回当前节点。
3. 递归搜索左子树，得到 `left`。
4. 递归搜索右子树，得到 `right`。
5. 如果 `left` 和 `right` 都不为空，说明 `p` 和 `q` 分别在当前节点两侧，当前节点就是最近公共祖先。
6. 如果只有一边不为空，返回不为空的那一边。
7. 如果两边都为空，返回 null。

**注意事项**

- 这是普通二叉树，不是二叉搜索树，不能用大小关系判断方向。
- 如果当前节点就是 `p` 或 `q`，当前节点可能就是答案。
- 返回值含义是：当前子树中是否找到了 `p` 或 `q`，以及找到的候选祖先。

补充：父指针 + 哈希表写法。

1. 先 DFS 建立 `当前节点 -> 父节点` 的映射。
2. 从 `q` 开始一路向上，把 `q` 到根节点路径上的所有节点加入 `HashSet`，包括 `q` 自己。
3. 从 `p` 开始一路向上走，第一个出现在集合中的节点就是最近公共祖先。

核心代码：

```java
class Solution {
    Map<TreeNode, TreeNode> parent = new HashMap<>();

    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        parent.put(root, null);
        dfs(root);

        Set<TreeNode> set = new HashSet<>();
        while (q != null) {
            set.add(q);
            q = parent.get(q);
        }

        while (p != null) {
            if (set.contains(p)) return p;
            p = parent.get(p);
        }

        return null;
    }

    private void dfs(TreeNode node) {
        if (node == null) return;
        if (node.left != null) parent.put(node.left, node);
        if (node.right != null) parent.put(node.right, node);
        dfs(node.left);
        dfs(node.right);
    }
}
```

易错点：

- 要把 `q` 自己也加入集合，因为一个节点可以是自己的祖先。
- 从 `p` 向上找时也应该先判断 `p` 自己，再移动到父节点。
- 比较的是节点对象引用，不是节点值。

### 二叉树中的最大路径和

**题目复述**

给定一棵非空二叉树，路径被定义为从树中任意节点出发，沿父子连接到达任意节点的序列。同一个节点在一条路径中最多出现一次，路径不一定经过根节点。请返回所有路径中的最大路径和。

**解答流程**

1. 使用后序遍历。
2. 对每个节点，先计算左子树向上能贡献的最大路径和。
3. 再计算右子树向上能贡献的最大路径和。
4. 如果某边贡献小于 0，就丢弃，按 0 计算。
5. 经过当前节点的最大路径和为 `node.val + leftGain + rightGain`。
6. 用这个值更新全局最大答案。
7. 当前节点向父节点只能返回一条路径，所以返回 `node.val + max(leftGain, rightGain)`。

**注意事项**

- 最大路径可以不经过根节点，所以要用全局变量记录答案。
- 向父节点返回时不能同时带左右两边，只能选一边。
- 全局答案初始化不能是 0，因为树中可能全是负数。
- 负贡献子树要丢弃，即 `Math.max(0, dfs(child))`。

## 九、图论 / Trie Graph

### 网格 DFS 的核心理念：类比二叉树
网格结构可以看作是“四叉树”的简化版图结构：
*   **相邻结点**：从二叉树的 `left/right` 扩展为网格的 `上下左右` 四个方向。
*   **Base Case**：从二叉树的 `root == null` 扩展为网格的 **“先污染后治理”**（即先递归，再通过坐标越界判断返回）。

### 网格 DFS 通用模版 (必背)
```java
void dfs(int[][] grid, int r, int c) {
    // 1. 判断 base case：坐标越界则返回
    if (!inArea(grid, r, c)) return;

    // 2. 判断 base case：非陆地或已访问则返回
    if (grid[r][c] != 1) return;

    // 3. 标记已访问：防止死循环（“陆地沉没”或标记为2）
    grid[r][c] = 2; 

    // 4. 访问上下左右四个相邻结点
    dfs(grid, r - 1, c);
    dfs(grid, r + 1, c);
    dfs(grid, r, c - 1);
    dfs(grid, r, c + 1);
}

// 辅助函数：判断坐标是否在网格内
boolean inArea(int[][] grid, int r, int c) {
    return 0 <= r && r < grid.length && 0 <= c && c < grid[0].length;
}
```

### 三个典型例题的变通思路

| 题目类型               | 核心变通逻辑                                                                                             | 关键点                                    |
| :--------------------- | :------------------------------------------------------------------------------------------------------- | :---------------------------------------- |
| **L695. 岛屿最大面积** | `return 1 + dfs(上) + dfs(下) + ...`                                                                     | 每层递归返回当前格子(1)加上四周面积。     |
| **L827. 最大人工岛**   | **两遍 DFS**：<br>1. 标记岛屿 ID 并记录对应面积。<br>2. 遍历海洋(0)，尝试连接四周不同 ID 的岛屿。        | 需使用 `HashSet` 避免重复连接同一个岛屿。 |
| **L463. 岛屿周长**     | **边界/海洋计数**：<br>1. 越界时返回 1（触碰到网格边缘）。<br>2. 遇到海洋(0)时返回 1（触碰到水域边缘）。 | 已访问过的陆地(2)返回 0。                 |

### 核心总结建议
*   **避免死循环**：在图中遍历必须有“标记”机制（已访问标记）。
*   **优雅的代码逻辑**：将边界判断（`inArea`）放在递归函数的入口处，而不是在调用递归前判断，可以让主逻辑变得极其简洁。
*   **“陆地沉没”隐患**：虽然将 `1` 改成 `0` 也能防死循环，但在需要区分“原始海洋”和“已遍历陆地”的复杂题目中（如周长问题），标记为 `2` 会更清晰。

### 岛屿数量（LeetCode 200，中等）

**题目复述**

给定一个由字符 `'1'` 和 `'0'` 组成的二维网格 `grid`，其中 `'1'` 表示陆地，`'0'` 表示水域。岛屿由上下左右四个方向相邻的陆地连接而成，斜方向不算连接。假设网格四周都被水包围，请计算网格中岛屿的数量。

**解答流程**

1. 遍历整个二维网格。
2. 如果当前位置是 `'1'`，说明发现一个新的岛屿，答案加 1。
3. 从这个位置开始 DFS 或 BFS，把与它相连的所有陆地都标记为已访问。
4. 标记方式可以把 `'1'` 改成 `'0'`，也可以额外使用 `visited` 数组。
5. 遍历结束后，答案就是岛屿数量。

**注意事项**

- 只允许上下左右四个方向，不能走斜方向。
- 如果直接修改原数组，把访问过的 `'1'` 改成 `'0'`，就不需要额外 visited。
- DFS 前要先判断是否越界。
- 空网格要注意边界，不过力扣通常会给合法矩阵。

---


**模版解答**


1.  **遍历网格**：使用双重循环访问每一个格子 `grid[r][c]`。
2.  **触发 DFS**：如果当前格子是未遍历的陆地 `'1'`：
    *   `count++`（发现一个新岛屿）。
    *   调用 `dfs(grid, r, c)` 将该岛屿及其所有相连陆地全部标记为已访问。
3.  **标记机制**：在 DFS 中，将遍历过的 `'1'` 改为 `'2'`（或其他非 `'1'` 字符），防止死循环和重复计数。

**代码逻辑示例 (Java)**

```java
public int numIslands(char[][] grid) {
    int count = 0;
    for (int r = 0; r < grid.length; r++) {
        for (int c = 0; c < grid[0].length; c++) {
            // 只有遇到未遍历的陆地 '1' 才开启新的 DFS
            if (grid[r][c] == '1') {
                count++;
                dfs(grid, r, c);
            }
        }
    }
    return count;
}

void dfs(char[][] grid, int r, int c) {
    // 1. 判断 base case：坐标越界则返回 (先污染后治理)
    if (!inArea(grid, r, c)) return;

    // 2. 判断 base case：非陆地（'0'）或已访问（'2'）则返回
    if (grid[r][c] != '1') return;

    // 3. 标记已访问：防止死循环
    grid[r][c] = '2'; 

    // 4. 访问上下左右四个相邻结点
    dfs(grid, r - 1, c);
    dfs(grid, r + 1, c);
    dfs(grid, r, c - 1);
    dfs(grid, r, c + 1);
}

// 辅助函数：判断坐标是否在网格内
boolean inArea(char[][] grid, int r, int c) {
    return 0 <= r && r < grid.length && 0 <= c && c < grid[0].length;
}
```

**注意事项**

*   **模版复用**：`dfs` 函数的结构完全遵循模版：越界检查 -> 类型检查 -> 标记访问 -> 四向递归。
*   **字符类型**：注意 `grid` 是 `char[][]`，判断时要用 `'1'` 而不是数字 `1`。
*   **返回值**：主函数返回的是开启 DFS 的次数，即岛屿的总数。
*   **inArea 优势**：有了 `inArea` 辅助函数，`dfs` 内部的逻辑变得极其清晰，不需要在每次递归调用前判断下标合法性。

**复杂度分析**
*   **时间复杂度**：$O(M \times N)$，每个格子最多被访问一次。
*   **空间复杂度**：$O(M \times N)$，最坏情况下（全是陆地）递归栈的深度。

### 腐烂的橘子（LeetCode 994，中等）

**题目复述**

给定一个二维网格 `grid`，其中 `0` 表示空格，`1` 表示新鲜橘子，`2` 表示腐烂橘子。每一分钟，腐烂橘子会使上下左右相邻的新鲜橘子腐烂。请返回直到没有新鲜橘子所需的最小分钟数。如果永远不可能腐烂所有橘子，返回 `-1`。

**解答流程**

1. 遍历网格，把所有初始腐烂橘子加入队列。
2. 同时统计新鲜橘子的数量 `fresh`。
3. 使用 BFS 按层扩散，每一层代表一分钟。
4. 每次从队列中取出当前层的腐烂橘子，尝试感染上下左右的新鲜橘子。
5. 每感染一个橘子，就把它改成 `2`，新鲜橘子数量减 1，并加入队列。
6. BFS 结束后，如果 `fresh == 0`，返回时间；否则返回 `-1`。

**注意事项**

- 多源 BFS：一开始所有腐烂橘子都要入队。
- 只有遇到 `1` 才能感染，不能重复感染 `2`。
- 感染后要立刻标记为 `2`，避免重复入队。
- 推荐循环条件写 `while (!queue.isEmpty() && fresh > 0)`，这样时间不会多加一轮。

### 课程表（LeetCode 207，中等）

**题目复述**

你需要学习 `numCourses` 门课程（编号 `0` 到 `n-1`）。`prerequisites[i] = [a, b]` 表示学课程 `a` 之前必须先学 `b`。判断是否可以完成所有课程（即图中是否存在环）。

---

### **核心知识点：拓扑排序 (Kahn 算法)**

拓扑排序是解决**有向无环图 (DAG)** 顺序问题的通用方法。如果一个有向图可以进行拓扑排序，则它一定无环。

#### **通用解题思路（BFS 模版）**

1.  **建图并统计入度**：
    *   使用邻接表 `adj` 存储图（由先修课指向后续课：`b -> a`）。
    *   使用数组 `indegree` 记录每个节点的入度（即该课有多少门先修课）。
2.  **初始化队列**：
    *   将所有 **入度为 0** 的节点（即没有先修课，可以直接学的课）入队。
3.  **BFS 拓扑遍历**：
    *   当队列不为空时，弹出队首节点 `u`，计数器 `count++`。
    *   遍历 `u` 指向的所有后续节点 `v`：
        *   将 `v` 的入度减 1（表示 `v` 的一门先修课已完成）。
        *   如果 `v` 的入度变为 0，则将 `v` 入队。
4.  **判断结果**：
    *   如果 `count == numCourses`，说明所有课程都学完了，返回 `true`。
    *   否则，说明图中存在环（某些课程入度永远减不到 0），返回 `false`。

---

**代码逻辑示例 (Java)**

```java
public boolean canFinish(int numCourses, int[][] prerequisites) {
    int[] indegree = new int[numCourses];
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());

    // 1. 建图 + 统计入度
    for (int[] cp : prerequisites) {
        indegree[cp[0]]++; // cp[1] -> cp[0]
        adj.get(cp[1]).add(cp[0]);
    }

    // 2. 初始入度为 0 的节点入队
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++) {
        if (indegree[i] == 0) queue.add(i);
    }

    // 3. BFS 拓扑排序
    int count = 0;
    while (!queue.isEmpty()) {
        int u = queue.poll();
        count++;
        for (int v : adj.get(u)) {
            if (--indegree[v] == 0) queue.add(v);
        }
    }

    return count == numCourses;
}
```

---

**注意事项**

*   **方向性**：`[a, b]` 表示 `b -> a`，建图时千万不要反，否则逻辑会颠倒。
*   **初始化**：邻接表 `adj` 必须先为每个节点 `new` 一个 `ArrayList`，避免 `IndexOutOfBounds`。
*   **环的本质**：在有向图中，只要有环，环内的节点入度永远不会减到 0，因此无法进入队列。
*   **DFS 变体**：此题也可用 DFS 配合“染色法”（0-未访问，1-访问中，2-已访问）来检测环，但 BFS（Kahn 算法）在处理“输出具体排序顺序”时更直观。

**复杂度分析**
*   **时间复杂度**：$O(V + E)$，其中 $V$ 是课程数，$E$ 是先修关系数。
*   **空间复杂度**：$O(V + E)$，用于存储邻接表和入度数组。

--- 


**解答流程**

拓扑排序 BFS：

1. 建图：`b -> a`，表示学完 `b` 后可以学 `a`。
2. 统计每门课的入度，即还有多少先修课程没完成。
3. 把所有入度为 0 的课程加入队列。
4. 不断从队列中取出课程，表示学完这门课。
5. 遍历它能解锁的后续课程，把后续课程入度减 1。
6. 如果某门后续课程入度变成 0，就加入队列。
7. 最后如果学过的课程数等于 `numCourses`，返回 true，否则说明有环，返回 false。

**注意事项**

- `[a, b]` 的方向是 `b -> a`，不要建反。
- 外层图 `List<List<Integer>> graph` 要先为每门课初始化一个空列表。
- 如果存在循环依赖，某些节点入度永远无法变成 0。
- DFS 染色法也能做，状态通常为：未访问、访问中、已访问。

### 子集（LeetCode 78，中等）

**题目复述**

给定一个元素互不相同的整数数组 `nums`，返回它的所有可能子集，也就是幂集。答案不能包含重复子集，顺序不限。

**解答流程**

写法一：枚举选择起点。

1. 每进入一层递归，都先把当前 `path` 加入答案。
2. 从 `start` 开始枚举可以选择的元素。
3. 选择 `nums[i]` 后进入下一层，下一层从 `i + 1` 开始。
4. 递归结束后撤销选择。

写法二：每个元素选或不选。

1. 第 `index` 层决定是否选择 `nums[index]`。
2. 先递归“不选”。
3. 再递归“选”，然后撤销。
4. 当 `index == nums.length` 时收集答案。

**注意事项**

- 子集问题不要求 path 长度固定。
- 如果用 start 写法，每一层都可以收集答案。
- `i + 1` 是避免重复选择同一个元素的关键。


**方法三：二进制位图法 (Bit Manipulation)**

**解答流程**

1.  **理解映射关系**：
    *   长度为 $n$ 的数组共有 $2^n$ 个子集。
    *   我们可以用一个长度为 $n$ 的二进制数来表示每个元素“选”或“不选”的状态：第 $i$ 位为 `1` 表示选 `nums[i]`，为 `0` 表示不选。
2.  **遍历所有状态**：
    *   外层循环：从 `0` 遍历到 $2^n - 1$（共有 $2^n$ 种组合）。
    *   内层循环：检查当前数字的每一位。如果第 $j$ 位为 `1`（即 `(i >> j) & 1 == 1`），则将 `nums[j]` 加入当前子集。
3.  **收集答案**：每轮内层循环结束后，将得到的子集加入结果集。

**代码逻辑示例 (Java)**

```java
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> res = new ArrayList<>();
    int n = nums.length;
    // 1 << n 即 2 的 n 次方
    for (int i = 0; i < (1 << n); i++) {
        List<Integer> sub = new ArrayList<>();
        for (int j = 0; j < n; j++) {
            // 检查第 j 位是否为 1
            if (((i >> j) & 1) == 1) {
                sub.add(nums[j]);
            }
        }
        res.add(sub);
    }
    return res;
}
```

**注意事项**

*   **适用范围**：由于 $2^{31}$ 会超出整数范围，此方法仅适用于 $n$ 较小的情况（LeetCode 此题 $n \le 10$，非常适合）。
*   **直观性**：这种方法不涉及递归和回溯，逻辑非常直接，本质是“枚举所有的二进制状态”。
*   **位运算技巧**：`(i >> j) & 1` 是判断第 $j$ 位是否为 1 的常用写法。

**复杂度分析**
*   **时间复杂度**：$O(n \times 2^n)$。一共有 $2^n$ 个状态，每个状态需要 $O(n)$ 的时间构造子集。
*   **空间复杂度**：$O(n)$。除了存储答案的空间外，仅需一个临时列表存储当前子集。

**题目复述**

3. 从 `start` 开始枚举候选数字。
4. 选择 `candidates[i]` 后，下一层仍然从 `i` 开始，因为数字可以重复使用。
5. 如果 `remain == 0`，收集答案。
6. 如果 `remain < 0`，停止当前分支。
7. 回溯时移除最后选择的数字。

**注意事项**

- 数字可以重复使用，所以递归传 `i`，不是 `i + 1`。
- 为避免组合重复，必须使用 `start` 控制选择顺序。
- 可以先排序，遇到 `candidates[i] > remain` 时提前 break。


**解答流程**

1.  **路径记录**：使用 `path` 保存当前组合。
2.  **状态传递**：使用 `remain` 表示当前还差多少（初始化为 `target`）。
3.  **递归与回溯**：
    *   从 `start` 下标开始向后枚举候选数字。
    *   **选择数字**：将 `candidates[i]` 加入 `path`，并将 `remain` 减去该值。
    *   **递归进入下一层**：因为数字可以重复使用，下一层的起始位置依然传入 **`i`**（而不是 `i + 1`）。
    *   **回溯撤销**：递归返回后，将 `candidates[i]` 从 `path` 中移除，恢复 `remain`。
4.  **终止条件**：
    *   `remain == 0`：找到一个有效组合，加入结果集。
    *   `remain < 0`：当前分支和已超过目标，直接返回（剪枝）。

---

### **核心分析：如何避免组合重复？**

这是组合类回溯算法中最关键的点。题目要求“组合不重复”，意味着 `[2, 2, 3]` 和 `[3, 2, 2]` 被视为同一个组合，只能出现一次。

**避免重复的核心机制：规定选择顺序（Start 变量控制）**

1.  **逻辑规定**：为了避免生成不同顺序的相同组合，我们人为规定：**在搜索树的每一层，我们只能选择当前数字及之后的数字，不能回过头选之前的数字。**
2.  **原理演示**：
    *   假设数组是 `[2, 3, 6, 7]`。
    *   第一条分支：选择了 `2` 之后，下一层可以选 `[2, 3, 6, 7]`。于是可以产生 `[2, 2, 3]`。
    *   第二条分支：选择了 `3` 之后，由于 `start` 变成了 `1`（即指向数字 `3`），下一层只能选 `[3, 6, 7]`。
    *   **结果**：由于选 `3` 之后不能再选 `2`，因此永远不会产生 `[3, 2, 2]` 这样与 `[2, 2, 3]` 重复的组合。
3.  **总结**：`start` 变量就像一个“单向阀门”，它确保了数组中的元素按照固定的先后顺序被加入 `path`，从而在根本上杜绝了乱序产生的重复。

---

**代码逻辑示例 (Java)**

```java
public List<List<Integer>> combinationSum(int[] candidates, int target) {
    List<List<Integer>> res = new ArrayList<>();
    backtrack(candidates, target, 0, new ArrayList<>(), res);
    return res;
}

private void backtrack(int[] nums, int remain, int start, List<Integer> path, List<List<Integer>> res) {
    if (remain == 0) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int i = start; i < nums.length; i++) {
        // 剪枝：如果当前数字已经大于剩余需求，且数组有序，则后续数字也可跳过
        if (remain - nums[i] < 0) continue; 

        path.add(nums[i]);
        // 关键点：传入 i 表示可以重复使用当前数字
        backtrack(nums, remain - nums[i], i, path, res);
        path.remove(path.size() - 1);
    }
}
```

**注意事项**

*   **重复使用 vs 重复组合**：
    *   “重复使用”指的是同一个数字可以在 `path` 里出现多次（递归传 `i`）。
    *   “重复组合”指的是集合内容相同但顺序不同的结果（靠 `start` 变量控制）。
*   **排序剪枝**：如果先对 `candidates` 进行排序，那么 `if (remain - nums[i] < 0)` 时可以直接 `break` 掉整个 `for` 循环，效率更高。

**复杂度分析**
*   **时间复杂度**：$O(S)$，其中 $S$ 为所有可行解的长度之和。最坏情况下呈指数级增长，但剪枝能大幅优化。
*   **空间复杂度**：$O(target)$。递归深度取决于目标值的大小。

--- 

这种通过 `start` 索引控制“搜索空间收缩”的技巧，是所有组合/子集问题的核心套路。

1. 用 `dfs(i, start)` 表示正在考虑 `s[i]` 后面是否切一刀，当前子串从 `start` 开始。
2. 如果不切，则当前子串继续向后扩展：`dfs(i + 1, start)`。
3. 如果切，则当前子串是 `s[start...i]`，必须先判断它是不是回文串。
4. 如果是回文串，把它加入路径，递归处理下一段：`dfs(i + 1, i + 1)`。
5. `i == n - 1` 时最后一个字符后面必须切，不能再选择“不切”。
6. 当 `i == n` 时，说明字符串已经完整分割，加入答案。

核心代码：

```java
class Solution {
    List<List<String>> ans = new ArrayList<>();
    List<String> path = new ArrayList<>();

    public List<List<String>> partition(String s) {
        dfs(s, 0, 0);
        return ans;
    }

    private void dfs(String s, int i, int start) {
        int n = s.length();
        if (i == n) {
            ans.add(new ArrayList<>(path));
            return;
        }

        if (i < n - 1) {
            dfs(s, i + 1, start);
        }

        if (isPalindrome(s, start, i)) {
            path.add(s.substring(start, i + 1));
            dfs(s, i + 1, i + 1);
            path.remove(path.size() - 1);
        }
    }

    private boolean isPalindrome(String s, int l, int r) {
        while (l < r) {
            if (s.charAt(l++) != s.charAt(r--)) return false;
        }
        return true;
    }
}
```

**注意事项**

- 这个写法的每一层是“切或不切”，不是枚举当前子串终点。
- 切之前必须判断 `s[start...i]` 是否为回文。
- `path` 是共享列表，递归后必须 `remove` 恢复状态。
- 最后一个字符后面一定要切，否则当前子串无法收尾。

## 十一、二分查找 Binary Search

### 搜索插入位置（LeetCode 35，简单）

**题目复述**

给定一个升序数组 `nums` 和目标值 `target`，如果目标值存在，返回它的下标；如果不存在，返回它应该按顺序插入的位置。要求时间复杂度为 `O(log n)`。

**解答流程**

1. 查找第一个大于等于 `target` 的位置。
2. 令 `l = 0`，`r = nums.length`，使用左闭右开区间。
3. 当 `l < r` 时取中点 `mid`。
4. 如果 `nums[mid] >= target`，答案在左边，`r = mid`。
5. 否则 `l = mid + 1`。
6. 最后返回 `l`。

**注意事项**

- 也可以用闭区间 `[0, n - 1]`。
- 返回位置可能等于 `nums.length`，表示插入到最后。
- 本质是 lower_bound。

### 搜索二维矩阵（LeetCode 74，中等）

**题目复述**

给定一个 $m \times n$ 矩阵，具备以下特性：
1.  每行中的整数从左到右按升序排列。
2.  每行的第一个整数大于前一行的最后一个整数。
判断矩阵中是否存在目标值 `target`。

---

### **方法一：逐行二分查找 (Binary Search Row by Row)**

这是最直观的二分应用，将二维搜索分解为多个一维搜索。

**解答流程**
1.  遍历矩阵的每一行（从 $0$ 到 $m-1$）。
2.  对每一行执行标准的一维二分查找。
3.  如果某一行找到了 `target`，立即返回 `true`。
4.  如果所有行都遍历完仍未找到，返回 `false`。

**复杂度分析**
*   **时间复杂度**：$O(m \log n)$。遍历 $m$ 行，每行二分需要 $\log n$。
*   **空间复杂度**：$O(1)$。

---

### **方法二：两次二分查找 (Two-Step Binary Search)**

利用矩阵“行首大于前行行尾”的特性，先锁定行，再锁定列。

**解答流程**
1.  **第一次二分（定位行）**：
    *   对矩阵的**第一列**（`matrix[0...m-1][0]`）进行二分查找。
    *   目标是找到**最后一个小于等于 `target` 的元素**所在的行索引 `row`。
2.  **有效性检查**：
    *   如果 `target` 比第一行第一个元素还小，说明不存在。
3.  **第二次二分（定位列）**：
    *   在确定的 `matrix[row]` 这一行内，执行标准一维二分查找。
    *   如果找到 `target` 返回 `true`，否则返回 `false`。

**代码逻辑示例 (Java)**
```java
// 1. 定位行：查找最后一个满足 matrix[i][0] <= target 的 i
int low = 0, high = m - 1;
while (low <= high) {
    int mid = low + (high - low) / 2;
    if (matrix[mid][0] == target) return true;
    if (matrix[mid][0] < target) low = mid + 1;
    else high = mid - 1;
}
int row = high; // 此时 high 指向最后一个 <= target 的位置
if (row < 0) return false;

// 2. 定位列：在 matrix[row] 中查找 target
int l = 0, r = n - 1;
while (l <= r) {
    int mid = l + (r - l) / 2;
    if (matrix[row][mid] == target) return true;
    if (matrix[row][mid] < target) l = mid + 1;
    else r = mid - 1;
}
return false;
```

**复杂度分析**
*   **时间复杂度**：$O(\log m + \log n) = O(\log(mn))$。这与将矩阵拉成一维数组进行二分的效率是完全一致的。
*   **空间复杂度**：$O(1)$。

---

**解法对比建议**
*   **逐行二分 (Method 1)**：逻辑最简单，但没有充分利用“行与行之间也有序”的特性。
*   **两次二分 (Method 2)**：充分利用了所有有序特性，效率最高，且逻辑上更符合人类在纸上寻找数字的习惯（先看哪一行，再在行内找）。


---

### 在排序数组中查找元素的第一个和最后一个位置（LeetCode 34，中等）

**题目复述**

给定一个非递减数组 `nums` 和目标值 `target`，找出目标值在数组中的开始位置和结束位置。如果不存在，返回 `[-1, -1]`。要求时间复杂度 `O(log n)`。

**解答流程**

1. 第一次二分找左边界：第一个 `>= target` 的位置。
2. 如果左边界越界或 `nums[left] != target`，返回 `[-1, -1]`。
3. 第二次二分找右边界：最后一个 `<= target` 的位置。
4. 返回 `[left, right]`。

**注意事项**

- 找左边界时通常用 `mid = l + (r - l) / 2`。
- 找右边界时如果写 `l = mid`，要用右中位数 `mid = l + (r - l + 1) / 2`。
- 两次二分的边界模板不要混用。

### 搜索旋转排序数组（LeetCode 33，中等）

**题目复述**

给定一个升序数组 `nums`，在某个未知位置进行了旋转（例如 `[0,1,2,4,5,6,7]` 变成 `[4,5,6,7,0,1,2]`）。数组中元素互不相同。给定 `target`，若存在返回下标，否则返回 `-1`。要求时间复杂度 $O(\log n)$。

---

### **核心分析：为什么旋转数组还能二分？**

旋转数组虽然整体无序，但由于它是由两个升序子数组拼接而成，具有一个关键性质：**无论从哪个位置将数组切成两半，其中至少有一半一定是依然有序的。**

**判定逻辑：**
1.  **确定哪一半有序**：通过比较 `nums[mid]` 和 `nums[left]`：
    *   如果 `nums[left] <= nums[mid]`，说明 **左半边 `[left, mid]` 是升序的**。
    *   否则，说明 **右半边 `[mid, right]` 是升序的**。
2.  **在有序区间判断范围**：
    *   如果左半边有序，且 `target` 落在 `[nums[left], nums[mid])` 之间，则 `right = mid - 1`。
    *   如果右半边有序，且 `target` 落在 `(nums[mid], nums[right]]` 之间，则 `left = mid + 1`。
3.  **收缩区间**：如果不落在有序区间内，则去另一半无序但可能包含旋转点的区间继续搜索。

---

**代码逻辑示例 (Java)**

```java
public int search(int[] nums, int target) {
    int left = 0, right = nums.length - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;

        // 1. 判断哪一半是有序的
        if (nums[left] <= nums[mid]) {
            // 左半边 [left, mid] 有序
            // 2. 判断 target 是否在有序的左半边范围内
            if (nums[left] <= target && target < nums[mid]) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        } else {
            // 右半边 [mid, right] 有序
            // 3. 判断 target 是否在有序的右半边范围内
            if (nums[mid] < target && target <= nums[right]) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
    }
    return -1;
}
```

---

**注意事项**

*   **边界条件（等号）**：`nums[left] <= nums[mid]` 中的等号非常重要，它处理了只有两个元素或 `left == mid` 的情况。
*   **无重复元素**：本题前提是元素互不相同。如果允许重复（如 LeetCode 81 题），当 `nums[left] == nums[mid]` 时将无法判断哪边有序，需要执行 `left++` 来缩小范围，此时时间复杂度最坏会退化到 $O(n)$。
*   **逻辑闭环**：二分查找的精髓在于通过一次比较排除掉一半的搜索空间。在旋转数组中，我们利用“局部有序”来实现这种排除。

**复杂度分析**
*   **时间复杂度**：$O(\log n)$。
*   **空间复杂度**：$O(1)$。

--- 

这种解法是二分查找的高级变形，核心在于**先找有序区间，再用区间范围约束 target**。

### 寻找旋转排序数组中的最小值（LeetCode 153，中等）

**题目复述**

给定一个升序数组经过若干次旋转后的结果，数组元素互不相同。请找出数组中的最小元素，要求时间复杂度为 `O(log n)`。

**解答流程**

1. 使用二分，比较 `nums[mid]` 和 `nums[r]`。
2. 如果 `nums[mid] > nums[r]`，说明最小值在右半边，`l = mid + 1`。
3. 否则说明最小值在左半边或者就是 mid，`r = mid`。
4. 当 `l == r` 时，返回 `nums[l]`。

**注意事项**

- 比较 `nums[mid]` 和右端点比比较左端点更稳定。
- 如果数组本身没有旋转，最终也能返回第一个元素。
- 本题元素不重复，所以无需处理 `nums[mid] == nums[r]` 的模糊情况。

---


---


### **核心分析：基于“属性边界”的二分思路**

二分查找的本质并非必须在“有序”数组中查找，而是寻找某种**“二段性属性”的边界**。在本题中，我们可以定义一个属性：**“元素是否小于等于数组最右侧的元素”**。

1.  **属性定义**：设数组最右侧元素为 `target = nums[n-1]`。
    *   对于旋转点左侧的所有元素，其值一定 **大于** `target`。
    *   对于旋转点及右侧的所有元素（即包含最小值的升序段），其值一定 **小于等于** `target`。
2.  **寻找边界**：最小值就是数组中 **第一个满足 `nums[i] <= target` 属性** 的元素。
3.  **判定逻辑**：
    *   如果 `nums[mid] > nums[right]`：说明 `mid` 落在左侧高位区，最小值一定在 `mid` 右侧，令 `left = mid + 1`。
    *   如果 `nums[mid] <= nums[right]`：说明 `mid` 已经落在右侧低位区（或者是最小值本身），最小值在 `mid` 左侧或就是 `mid`，令 `right = mid`。

---

**代码逻辑示例 (Java)**

```java
public int findMin(int[] nums) {
    int left = 0;
    int right = nums.length - 1;

    // 二分寻找第一个满足 nums[i] <= nums[right] 的 i
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] > nums[right]) {
            // mid 在左侧上升段，最小值在右边
            left = mid + 1;
        } else {
            // mid 在右侧上升段，最小值在 mid 或左边
            right = mid;
        }
    }
    return nums[left];
}
```

---

**注意事项**

*   **右端点稳定性**：为什么比较 `nums[mid]` 和 `nums[right]`？因为 `nums[right]` 在二分过程中始终代表当前搜索区间的“潜在上限”。即使数组没旋转（本身有序），`nums[mid] <= nums[right]` 也会持续收缩右边界直到指向第一个元素。
*   **左闭右开 vs 闭区间**：由于我们要找的是“第一个满足条件的点”，采用 `while (left < right)` 且 `right = mid` 的写法能自然收敛到目标点。
*   **无重复元素**：如果存在重复元素（如 LeetCode 154），当 `nums[mid] == nums[right]` 时，我们无法判断 `mid` 在哪一段，此时只能令 `right--` 线性缩小范围。

**复杂度分析**
*   **时间复杂度**：$O(\log n)$。
*   **空间复杂度**：$O(1)$。

--- 

**总结提炼**：
本题将二分查找抽象为了：在一个具有 `[False, False, ..., True, True]` 属性分布的数组中，寻找第一个 `True` 的位置。这种**“寻找属性转折点”**的思维是解决复杂二分问题的利器。

### 寻找两个正序数组的中位数（LeetCode 4，困难）

**题目复述**

给定两个正序数组 `nums1` 和 `nums2`，数组长度分别为 `m` 和 `n`。请找出两个数组合并后的中位数，要求时间复杂度为 `O(log(m+n))`。

**解答流程**

常用思路：找第 k 小。

1. 如果总长度为奇数，找第 `(m + n) / 2 + 1` 小的数。
2. 如果总长度为偶数，找第 `(m + n) / 2` 小和第 `(m + n) / 2 + 1` 小的平均值。
3. 写函数 `getKth(nums1, start1, nums2, start2, k)`。
4. 每次比较两个数组从当前起点往后第 `k / 2` 个元素。
5. 较小的一边前 `k / 2` 个元素不可能是第 k 小，可以整体丢弃。
6. 更新起点和 k，直到 k 为 1 或某个数组被用完。

**注意事项**

- k 是从 1 开始计数，不是下标。
- 某个数组剩余长度不足 `k / 2` 时，要取它最后一个元素比较。
- 返回偶数长度中位数时要转 double，避免整数除法。

### 字符串解码

**题目复述**

给定编码字符串 `s`，编码规则为 `k[encoded_string]`，表示括号内字符串重复 `k` 次。编码可以嵌套，要求返回解码后的字符串。

**解答流程**

1. 用 `numStack` 保存进入括号前的重复次数。
2. 用 `strStack` 保存进入括号前已经构造好的字符串。
3. 遇到数字时累积 `multi = multi * 10 + digit`，处理多位数。
4. 遇到 `[` 时，保存当前 `multi` 和 `cur`，然后重置 `multi` 与 `cur`。
5. 遇到字母时追加到 `cur`。
6. 遇到 `]` 时，弹出重复次数和上一层字符串，把当前字符串重复拼接回上一层。

核心代码：

```java
class Solution {
    public String decodeString(String s) {
        Deque<Integer> numStack = new ArrayDeque<>();
        Deque<StringBuilder> strStack = new ArrayDeque<>();
        StringBuilder cur = new StringBuilder();
        int multi = 0;

        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) {
                multi = multi * 10 + (c - '0');
            } else if (c == '[') {
                numStack.push(multi);
                strStack.push(cur);
                multi = 0;
                cur = new StringBuilder();
            } else if (c == ']') {
                int repeat = numStack.pop();
                StringBuilder prev = strStack.pop();
                for (int i = 0; i < repeat; i++) {
                    prev.append(cur);
                }
                cur = prev;
            } else {
                cur.append(c);
            }
        }

        return cur.toString();
    }
}
```

**注意事项**

- 栈保存的是“进入括号前的现场”，右括号负责恢复现场。
- 数字可能是多位数，不能只处理单个字符。
- 原始字符串不含数字，数字只表示重复次数。
- 时间复杂度和最终输出长度相关。

---

## 十三、堆 Heap

### 数组中的第 K 个最大元素（LeetCode 215，中等）

**题目复述**

给定整数数组 `nums` 和整数 `k`，返回数组中第 `k` 个最大的元素。注意是排序后的第 k 大，不是第 k 个不同的元素。

**解答流程**

小顶堆写法：

1. 创建容量最多为 k 的小顶堆。
2. 遍历数组，把元素加入堆。
3. 如果堆大小超过 k，就弹出堆顶最小值。
4. 遍历结束后，堆顶就是第 k 大元素。

快速选择写法：

1. 第 k 大等价于排序后下标 `n - k`。
2. 使用快速选择 partition。
3. 每次只递归目标下标所在的一边。

**注意事项**

- “第 k 大”不是“第 k 个不同值”。
- 小顶堆复杂度 `O(n log k)`，快速选择平均 `O(n)`。
- Java 中 `PriorityQueue` 默认是小顶堆。

### 跳跃游戏（LeetCode 55，中等）

**题目复述**

给定非负整数数组 `nums`，每个元素表示从该位置最多可以跳跃的长度。初始位置在下标 0，判断是否能够到达最后一个下标。

**解答流程**

1. 维护当前能到达的最远位置 `farthest`。
2. 从左到右遍历下标 `i`。
3. 如果 `i > farthest`，说明当前位置不可达，返回 false。
4. 否则更新 `farthest = max(farthest, i + nums[i])`。
5. 如果 `farthest >= n - 1`，可以返回 true。

**注意事项**

- 只关心能到达的最远位置，不需要真的模拟每种跳法。
- 当当前位置超过最远可达范围时，后面都不用看。
- `nums[i]` 表示最多跳，不是必须跳这么远。

### 跳跃游戏 II（LeetCode 45，中等）

**题目复述**

给定一个非负整数数组 `nums`，你初始在下标 `0`。每个元素表示你在该位置可以跳跃的最大长度。假设你总是可以到达最后一个位置，请返回到达最后一个下标所需的**最少跳跃次数**。

**解答流程（基于区间的贪心法）**

该代码通过维护一个“当前跳跃步数能覆盖的区间 `[l, r]`”来逐步推进：

1.  **初始化**：跳跃次数 `count = 0`，当前区间左边界 `l = 0`，右边界 `r = 0`，目前能达到的最远位置 `longest = 0`。
2.  **循环扩展**：只要 `longest` 还没到达数组末尾（`nums.length - 1`）：
    *   **遍历当前区间**：在当前跳跃次数能到达的范围 `[l, r]` 内，计算下一步能跳到的最远位置。
    *   **更新最远距离**：`longest = Math.max(longest, i + nums[i])`。
    *   **步数增加**：完成当前区间的扫描后，`count++`（代表进行了一次跳跃）。
    *   **更新下一跳区间**：
        *   新左边界 `l = r + 1`（跳出当前范围）。
        *   新右边界 `r = longest`（下一跳最远能覆盖到的位置）。
3.  **返回结果**：当循环结束，`count` 即为最少跳跃次数。

**代码逻辑示例 (Java)**

```java
public int jump(int[] nums) {
    if (nums.length == 1) return 0;
    int count = 0;
    int l = 0, r = 0;
    int longest = 0;
    
    // 只要最远还没覆盖到终点，就继续跳
    while (longest < nums.length - 1) {
        // 在当前能跳到的区间 [l, r] 内，寻找下一跳能达到的最远点
        for (int i = l; i <= r; i++) {
            longest = Math.max(longest, i + nums[i]);
        }
        count++;    // 进行一跳
        l = r + 1;  // 更新下一跳的左边界
        r = longest; // 更新下一跳的右边界
    }
    return count;
}
```

---

### **核心分析：为什么这种贪心法有效？**

1.  **分级思想**：这种解法本质上是将跳跃过程看作“分层”。
    *   第 0 层：下标 `[0, 0]`，跳 0 次。
    *   第 1 层：下标 `[1, nums[0]]`，跳 1 次。
    *   第 2 层：从第 1 层所有位置中能跳到的最远范围...
2.  **局部最优解**：每一跳我们都尽量去覆盖最远的范围，这样能保证用最少的跳跃次数覆盖到终点。
3.  **区间推移**：代码中的 `l` 和 `r` 实际上标记了“第 $k$ 次跳跃”所能落脚的所有可能位置的区间。

**注意事项**

*   **单元素检查**：如果数组只有一个元素，直接返回 `0`（代码中的 `while` 逻辑也能处理，但显式检查更清晰）。
*   **边界判断**：`while (longest < nums.length - 1)` 确保了只要终点还没进入“当前跳跃能力范围”，就必须再跳一次。
*   **代码简洁性**：相比于维护 `end` 的传统贪心写法，这种 `l, r` 区间写法逻辑上更像广度优先搜索（BFS）的变体，非常直观。

**复杂度分析**
*   **时间复杂度**：$O(n)$，尽管有嵌套循环，但 `i` 始终是从 `0` 到 `n-1` 递增访问的，每个元素只访问一次。
*   **空间复杂度**：$O(1)$，仅使用了常数个变量。

--- 

这种写法通过明确的区间移动展示了跳跃的“层级”感，非常适合在面试中一边写一边向面试官解释逻辑。

### 划分字母区间（LeetCode 763，中等）

**题目复述**

给定字符串 `s`，需要将它划分为尽可能多的片段，使得每个字母最多只出现在一个片段中。返回每个片段的长度。

**解答流程**

### 多数元素（LeetCode 169，简单）

**题目复述**

给定一个大小为 `n` 的数组 `nums`，返回其中的**多数元素**。多数元素是指在数组中出现次数**大于** `⌊ n/2 ⌋` 的元素。题目保证多数元素一定存在。

---

### **方法一：摩尔投票法 (Boyer-Moore Voting Algorithm)**

这是解决此问题的最优解法，利用了“抵消”的思想。

**解答流程**
1.  **初始化**：设置候选人 `candidate = null`，票数统计 `count = 0`。
2.  **遍历数组**：
    *   如果 `count == 0`，将当前元素设为 `candidate`。
    *   如果当前元素等于 `candidate`，则 `count++`。
    *   如果当前元素不等于 `candidate`，则 `count--`（互相抵消）。
3.  **返回结果**：遍历结束后，`candidate` 即为所求。

**核心逻辑分析**
*   由于多数元素的次数大于 $n/2$，即使它和其他所有元素一一抵消，最后剩下的依然是它。

**复杂度分析**
*   **时间复杂度**：$O(n)$。
*   **空间复杂度**：$O(1)$。

---

### **方法二：排序法 (Sorting Method)**

这是利用统计学特性的最简解法。

**解答流程**
1.  **执行排序**：将数组 `nums` 进行升序或降序排序。
2.  **取中点**：返回下标为 `n / 2` 的元素（即 `nums[nums.length / 2]`）。

**核心逻辑分析**
*   如果一个数字出现的次数超过了一半，那么无论它偏大还是偏小，在排序后的数组中，它必然会覆盖到数组的中点位置。

**复杂度分析**
*   **时间复杂度**：$O(n \log n)$，取决于排序算法。
*   **空间复杂度**：$O(\log n)$，排序所需的栈空间。

---

**注意事项**

*   **题目保证存在**：因为题目保证了多数元素一定存在，所以摩尔投票法不需要在结束后再次遍历数组来验证该候选人是否真的超过一半。
*   **抵消本质**：摩尔投票法本质上是将不同元素结对抵消，剩下的必是多数派。
*   **算法选择**：面试时应首选摩尔投票法（空间 $O(1)$），如果时间紧迫或代码写不出来，排序法是一个极佳的备选方案。


### 颜色分类（LeetCode 75，中等）

**题目复述**

给定一个包含红色、白色和蓝色（分别用 `0`、`1` 和 `2` 表示）的数组 `nums`，**原地**对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色的顺序排列。要求不能使用库函数排序。

---

### **方法一：荷兰国旗算法 (Dutch National Flag - 三指针)**

这是最经典的一趟遍历（One-pass）解法。

**解答流程**
1.  **初始化**：`p0` 指向 0 的右边界（初始为 0），`p2` 指向 2 的左边界（初始为 `n-1`），`i` 为当前扫描指针。
2.  **遍历数组**（直到 `i > p2`）：
    *   若 `nums[i] == 0`：交换 `nums[i]` 和 `nums[p0]`，随后 `p0++`, `i++`。
    *   若 `nums[i] == 2`：交换 `nums[i]` 和 `nums[p2]`，随后 `p2--`（注意：此时 `i` 不动，因为换回来的数还没检查）。
    *   若 `nums[i] == 1`：无需操作，直接 `i++`。

**核心注意事项**
*   **为什么遇到 0 之后 `i++` 而遇到 2 之后不加？** 因为 `p0` 交换过来的数一定是 `1`（由于 `i` 已经扫描过前面的区域），而 `p2` 交换过来的数可能是任何值（可能是 `0`），需要原地再次判断。

---

### **方法二：两次双指针法 (Two-Pass Two-Pointer)**

如果你觉得三指针的逻辑较难处理边界，可以使用这个更稳健的两次遍历解法。

**解答流程**
1.  **第一遍遍历（处理 0）**：
    *   设定一个指针 `ptr = 0`。
    *   从左到右遍历数组，只要遇到 `nums[i] == 0`，就将其与 `nums[ptr]` 交换，并执行 `ptr++`。
    *   遍历结束后，所有的 `0` 都被移到了数组最前面。
2.  **第二遍遍历（处理 1）**：
    *   **从当前的 `ptr` 位置开始**继续向后遍历。
    *   只要遇到 `nums[i] == 1`，就将其与 `nums[ptr]` 交换，并执行 `ptr++`。
    *   遍历结束后，所有的 `1` 都排在了 `0` 的后面，剩下的自然就是 `2`。

**代码逻辑示例 (Java)**
```java
public void sortColors(int[] nums) {
    int n = nums.length;
    int ptr = 0;
    // 第一遍：把所有的 0 换到前面
    for (int i = 0; i < n; i++) {
        if (nums[i] == 0) {
            swap(nums, i, ptr);
            ptr++;
        }
    }
    // 第二遍：把所有的 1 换到 0 的后面
    for (int i = ptr; i < n; i++) {
        if (nums[i] == 1) {
            swap(nums, i, ptr);
            ptr++;
        }
    }
}
```

---

**注意事项总结**

*   **原地排序**：题目明确要求不能申请额外数组，且不能直接调用 `Arrays.sort()`。
*   **稳定性 vs 简洁性**：
    *   三指针（方法一）只需要一次遍历，常数项更小，是面试官最想看到的解法。
    *   两次双指针（方法二）逻辑极其清晰，几乎不会写错，是保底的最佳选择。

**复杂度分析**
*   **时间复杂度**：均为 $O(n)$。方法一遍历一次，方法二遍历两次。
*   **空间复杂度**：均为 $O(1)$。

--- 

这种将“极致优化”与“稳健逻辑”对比记忆的方法，能显著提高你在高压面试下的容错率。

### 寻找重复数（LeetCode 287，中等）

**题目复述**

给定一个包含 `n + 1` 个整数的数组 `nums`，其中每个整数都在 `[1, n]` 范围内。数组中只有一个重复数字，但它可能出现多次。要求找出这个重复数字，并且不能修改数组，额外空间复杂度为 `O(1)`。

**解答流程**

快慢指针写法：

1. 把数组看成链表：下标 `i` 指向 `nums[i]`。
2. 因为有重复数字，所以一定会形成环。
3. 慢指针每次走一步：`slow = nums[slow]`。
4. 快指针每次走两步：`fast = nums[nums[fast]]`。
5. 第一次相遇后，把一个指针放回起点。
6. 两个指针每次都走一步，再次相遇的位置就是重复数字。

**注意事项**

- 这是环形链表 II 的思想迁移。
- 不能修改数组，所以原地哈希或排序不符合题目要求。
- 起点通常从 `0` 开始，因为 `nums[0]` 会进入 `[1, n]` 的链表区域。

## 附录、排序模板 Sorting Templates

### 快速排序

**题目复述**

给定数组，对区间 `[l, r]` 原地升序排序。常用模板是 Hoare 双指针分区。

**解答流程**

1. 如果 `l >= r`，区间长度小于等于 1，直接返回。
2. 取中间值作为基准值 `x`。
3. `i` 从左侧区间外开始，`j` 从右侧区间外开始。
4. `i` 向右找到第一个 `>= x` 的数。
5. `j` 向左找到第一个 `<= x` 的数。
6. 如果 `i < j`，交换二者。
7. 分区结束后递归排序 `[l, j]` 和 `[j + 1, r]`。

Java 模板：

```java
public static void quickSort(int[] q, int l, int r) {
    if (l >= r) return;

    int i = l - 1;
    int j = r + 1;
    int x = q[l + (r - l) / 2];

    while (i < j) {
        do i++; while (q[i] < x);
        do j--; while (q[j] > x);

        if (i < j) {
            int t = q[i];
            q[i] = q[j];
            q[j] = t;
        }
    }

    quickSort(q, l, j);
    quickSort(q, j + 1, r);
}
```

**注意事项**

- 这个模板中，基准值 `x` 不一定被放到最终位置。
- 递归边界必须配套写成 `[l, j]` 和 `[j + 1, r]`。
- `do while` 配合初始值 `i = l - 1, j = r + 1`。
- 比较条件用严格的 `< x` 和 `> x`，大量重复元素时也能推进。

---

### 归并排序

**题目复述**

给定数组，对区间 `[l, r]` 升序排序。归并排序使用分治思想：先拆分左右区间，再合并两个有序区间。

**解答流程**

1. 如果 `l >= r`，直接返回。
2. 取中点 `mid`。
3. 递归排序左半区间 `[l, mid]`。
4. 递归排序右半区间 `[mid + 1, r]`。
5. 用双指针合并两个有序区间到临时数组 `tmp`。
6. 把 `tmp` 中结果复制回原数组 `q[l...r]`。

Java 模板：

```java
static int[] tmp;

public static void mergeSort(int[] q, int l, int r) {
    if (l >= r) return;

    int mid = l + (r - l) / 2;
    mergeSort(q, l, mid);
    mergeSort(q, mid + 1, r);

    int k = 0, i = l, j = mid + 1;
    while (i <= mid && j <= r) {
        if (q[i] <= q[j]) tmp[k++] = q[i++];
        else tmp[k++] = q[j++];
    }

    while (i <= mid) tmp[k++] = q[i++];
    while (j <= r) tmp[k++] = q[j++];

    for (i = l, j = 0; i <= r; i++, j++) {
        q[i] = tmp[j];
    }
}
```

**注意事项**

- 这是自顶向下归并排序：先从大区间向下拆，再从小区间向上合并。
- 合并时相等元素优先取左边：`q[i] <= q[j]`，可以保证稳定性。
- 临时数组 `tmp` 通常提前创建一次，避免每层递归重复创建。
- 时间复杂度稳定为 `O(n log n)`，额外空间复杂度 `O(n)`。

## 快速复习口诀

- 哈希：看见“快速查找、分组、去重”，先想 Map / Set。
- 双指针：看见“有序、两端、原地移动”，先想左右指针或快慢指针。
- 滑动窗口：看见“连续子串 / 子数组 + 最长最短”，先想窗口。
- 前缀和：看见“连续子数组和为 K，且有负数”，优先前缀和 + 哈希。
- 单调队列：看见“滑动窗口最大/最小值”，用 Deque 存下标。
- 矩阵：原地标记小心第一行第一列，螺旋遍历小心边界重复。
- 链表：改指针前先保存 next，删除头节点先想 dummy。
- 树：递归三件事，当前节点做什么、左子树要什么、右子树要什么。
- 图：DFS/BFS 必须有 visited 或原地标记；课程表先想拓扑排序。
- 回溯：看见“所有方案”，想选择、递归、撤销选择。
- 二分：先明确二分的是下标、答案，还是某个性质边界。
- 栈：看见“括号嵌套、保存现场、下一个更大/更小”，先想栈。
- 堆：看见“前 K 个、动态最值、中位数”，先想堆。
- 贪心：每一步维护当前能到达的最优边界。
- 技巧：位运算、摩尔投票、荷兰国旗、快慢指针是常见压轴模板。
