以下是本会话中涉及的 Git 命令汇总，按场景分类：

## 1. 查看状态
```bash
git status              # 查看当前分支状态
git branch              # 查看本地分支列表
git branch -vv          # 查看分支及对应的远程追踪分支
```

## 2. 比较差异
```bash
# 本地已提交但未推送 vs 远程
git log origin/HEAD..HEAD
git log HEAD..origin/HEAD
git diff origin/HEAD..HEAD

# 当前分支 vs 远程对应分支（PowerShell 需加引号）
git log "@{u}..HEAD"
git log "HEAD..@{u}"
git diff "@{u}..HEAD"

# 两个本地分支比较
git diff A..B
git diff --name-only A B          # 只看文件名
git difftool A B                   # 图形化比较

# 当前分支 vs 远程对应分支
git fetch                          # 先更新远程信息
git diff @{upstream}
git diff --name-only @{upstream}
git log @{upstream}..HEAD          # 本地比远程多哪些
git log HEAD..@{upstream}          # 远程比本地多哪些
```

## 3. 分支操作
```bash
# 创建新分支
git checkout -b test-branch

# 切换分支
git switch 分支名
git checkout 分支名

# 删除本地分支
git branch -D 分支名

# 移除远程追踪关系
git branch --unset-upstream 分支名
```

## 4. 丢弃修改
```bash
git checkout -- .        # 丢弃已修改但未 add 的文件
git restore .              # 同上（新版 Git 推荐）
git clean -fd             # 删除所有未跟踪文件和目录（永久删除，慎用）
```

## 5. 暂存与提交
```bash
git stash push -m "描述"   # 暂存当前修改
git stash pop              # 恢复最近一次暂存
git add .                  # 添加到暂存区
git commit -m "描述"       # 提交到本地分支
```

## 6. 远程操作
```bash
git fetch                  # 更新远程分支信息（不合并）
```

# 五、Merge、Revert、Cherry-pick 的区别

## Merge

```powershell
git merge <branch>
```

作用：

- 合并一个分支的提交历史；
- 可能带入分支中的多个提交；
- 分支已经在历史中时可能显示 `Already up to date`；
- 可能创建 Merge commit。

本次不适合直接 merge 原功能分支，因为它包含大量旧 merge 和 revert 历史。

## Revert

```powershell
git revert <commit>
```

作用：

- 创建反向提交；
- 抵消目标提交的代码效果；
- 不删除历史。

撤销 Merge commit 时需要指定主线：

```powershell
git revert -m 1 <merge-commit>
```

## Cherry-pick

```powershell
git cherry-pick <commit>
```

作用：

- 只选取一个指定提交的差异；
- 将其应用到当前分支；
- 产生一个新提交。

本次只需要恢复：

```text
c5b290930 完善产品名称下拉筛选
```

因此 Cherry-pick 是最合适的方法。
