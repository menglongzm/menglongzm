一、哈希 Hash

核心思想：用 O(1) 查找代替 O(n) 扫描。看到「快速查找、分组、去重」先想 Map/Set。

1.1 两数之和

找两不同下标使 nums[i]+nums[j]==target。

核心：建 Map<值,下标>；遍历时先查补数 need=target-nums[i]，找到返回，没找到再存入。

public int[] twoSum(int[] nums, int target) {
    Map<Integer,Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int need = target - nums[i];
        if (map.containsKey(need)) return new int[]{map.get(need), i};
        map.put(nums[i], i);
    }
    return new int[0];
}
易错：必须先查补数再放当前值，避免同一元素用两次。

1.2 字母异位词分组

把字母异位词分到同一组。

核心：建 Map<String,List>；为每字符串生成 key：排序字符数组或统计 26 字母频次拼 key。

public List<List<String>> groupAnagrams(String[] strs) {
    Map<String,List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] c = s.toCharArray();
        Arrays.sort(c);
        String key = new String(c);
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
易错：频次 key 要加分隔符如 1#0#2#，避免 [1,11] 和 [11,1] 混淆。

1.3 最长连续序列

未排序数组找数字连续的最长序列长度，O(n)。

核心：全部入 HashSet 去重；只对 num-1 不在 Set 中的「起点」向后数。

public int longestConsecutive(int[] nums) {
    Set<Integer> set = new HashSet<>();
    for (int n : nums) set.add(n);
    int ans = 0;
    for (int n : set) {
        if (!set.contains(n - 1)) { // 只从起点开始数
            int cur = n, count = 1;
            while (set.contains(cur + 1)) { cur++; count++; }
            ans = Math.max(ans, count);
        }
    }
    return ans;
}
易错：关键优化是「只从起点开始数」，否则退化 O(n²)。

二、双指针 Two Pointers

核心思想：两指针相对移动代替嵌套循环。看到「有序、两端、原地移动」先想左右或快慢指针。

2.1 移动零

把所有 0 移到末尾，保持非零相对顺序，原地操作。

核心：慢指针 slow 标记下一个非零位置；快指针遍历，遇到非零就和 slow 交换再 slow++。

public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            int t = nums[slow]; nums[slow] = nums[fast]; nums[fast] = t;
            slow++;
        }
    }
}

2.2 盛最多水的容器

两竖线 + x 轴组成容器，返回最大容量。

核心：左右指针向中间靠；每次移动短板一侧。

public int maxArea(int[] h) {
    int l = 0, r = h.length - 1, ans = 0;
    while (l < r) {
        int area = Math.min(h[l], h[r]) * (r - l);
        ans = Math.max(ans, area);
        if (h[l] < h[r]) l++; else r--;
    }
    return ans;
}
易错：面积由短板决定，移动高板无意义；不能用局部最高柱贪心。

2.3 三数之和

找不重复三元组 [a,b,c] 使 a+b+c==0。

核心：先排序；外层固定 nums[i]（跳过 nums[i]==nums[i-1] 去重），内层左右指针；和等于 0 收集并跳过左右重复值。

public List<List<Integer>> threeSum(int[] nums) {
    List<List<Integer>> ans = new ArrayList<>();
    Arrays.sort(nums);
    for (int i = 0; i < nums.length - 2; i++) {
        if (nums[i] > 0) break;
        if (i > 0 && nums[i] == nums[i - 1]) continue;
        int l = i + 1, r = nums.length - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum == 0) {
                ans.add(Arrays.asList(nums[i], nums[l], nums[r]));
                while (l < r && nums[l] == nums[l + 1]) l++;
                while (l < r && nums[r] == nums[r - 1]) r--;
                l++; r--;
            } else if (sum < 0) l++; else r--;
        }
    }
    return ans;
}
易错：排序是去重和双指针的前提；nums[i]>0 可直接结束。

2.4 接雨水

柱子高度数组，计算总接水量。

核心（双指针）：左右指针 + leftMax、rightMax；哪边矮处理哪边：接水量 min(leftMax,rightMax)-height[i]。

public int trap(int[] h) {
    int l = 0, r = h.length - 1, lMax = 0, rMax = 0, ans = 0;
    while (l < r) {
        if (h[l] < h[r]) {
            if (h[l] >= lMax) lMax = h[l]; else ans += lMax - h[l];
            l++;
        } else {
            if (h[r] >= rMax) rMax = h[r]; else ans += rMax - h[r];
            r--;
        }
    }
    return ans;
}
易错：关键是「较矮侧的上限已确定」。

三、滑动窗口 Sliding Window

核心思想：维护连续区间，右端扩张、左端收缩。看到「连续子串/子数组 + 最长最短」先想窗口。

窗口有两种形态：可变长（扩张到不合法时收缩）和定长（大小固定为 p.length()）。共用同一套左右指针骨架，区别在收缩条件。

3.1 无重复字符的最长子串

找不含重复字符的最长连续子串长度。

核心：哈希表记每字符最后位置；右指针遍历，若当前字符在窗口内则 left=max(left,lastIndex+1)；更新 ans=max(ans,right-left+1)。

public int lengthOfLongestSubstring(String s) {
    Map<Character,Integer> map = new HashMap<>();
    int left = 0, ans = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (map.containsKey(c)) left = Math.max(left, map.get(c) + 1);
        map.put(c, right);
        ans = Math.max(ans, right - left + 1);
    }
    return ans;
}
易错：left 只能向右移，必须用 max；子串必须连续，别和子序列混淆。

3.2 找到字符串中所有字母异位词

找 s 中所有 p 的字母异位词子串起始下标。

核心：定长窗口 p.length()；两个 26 长度数组记频次；窗口右移时加入右侧新字符、移除左侧旧字符；用 Arrays.equals 比较。

public List<Integer> findAnagrams(String s, String p) {
    List<Integer> ans = new ArrayList<>();
    if (s.length() < p.length()) return ans;
    int[] sc = new int[26], pc = new int[26];
    for (int i = 0; i < p.length(); i++) { sc[s.charAt(i)-'a']++; pc[p.charAt(i)-'a']++; }
    if (Arrays.equals(sc, pc)) ans.add(0);
    for (int i = p.length(); i < s.length(); i++) {
        sc[s.charAt(i)-'a']++; sc[s.charAt(i-p.length())-'a']--;
        if (Arrays.equals(sc, pc)) ans.add(i - p.length() + 1);
    }
    return ans;
}
易错：s.length()<p.length() 直接返回空列表。

四、子串 / 前缀和 / 队列

核心思想：前缀和把「区间和」转化为「两个前缀之差」；单调队列在滑动中维护动态最值。

4.1 和为 K 的子数组

统计和为 k 的连续非空子数组数量，可能有负数。

核心：前缀和 sum + 哈希表记每种前缀和出现次数；初始化 map.put(0,1)；遍历时先查 sum-k 出现次数累加，再记当前 sum。

public int subarraySum(int[] nums, int k) {
    Map<Integer,Integer> map = new HashMap<>();
    map.put(0, 1);
    int sum = 0, ans = 0;
    for (int n : nums) {
        sum += n;
        if (map.containsKey(sum - k)) ans += map.get(sum - k);
        map.merge(sum, 1, Integer::sum);
    }
    return ans;
}
易错：不能用滑动窗口（负数使窗口和不具备单调性）；必须先查 sum-k 再记当前 sum。

4.2 滑动窗口最大值

窗口大小 k 滑动，返回每窗口最大值。

核心：双端队列存下标，对应值单调递减；队头滑出窗口就移除；队尾小于等于当前值的全部移除；i>=k-1 时队头即最大值。

public int[] maxSlidingWindow(int[] nums, int k) {
    int[] ans = new int[nums.length - k + 1];
    Deque<Integer> dq = new LinkedList<>();
    for (int i = 0; i < nums.length; i++) {
        while (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst();
        while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) dq.pollLast();
        dq.offerLast(i);
        if (i >= k - 1) ans[i - k + 1] = nums[dq.peekFirst()];
    }
    return ans;
}
易错：队列存下标不存值；移除队尾用 <= 可去掉旧相同值。

4.3 最小覆盖子串

找 s 中最短连续子串，包含 t 中所有字符及次数。

核心：哈希表记 t 需要次数；右指针扩张加入字符；窗口达标时尝试左指针收缩；每次达标时更新最短答案。

public String minWindow(String s, String t) {
    Map<Character,Integer> need = new HashMap<>(), win = new HashMap<>();
    for (char c : t.toCharArray()) need.merge(c, 1, Integer::sum);
    int l = 0, r = 0, valid = 0, start = 0, len = Integer.MAX_VALUE;
    while (r < s.length()) {
        char c = s.charAt(r++);
        if (need.containsKey(c)) {
            win.merge(c, 1, Integer::sum);
            if (win.get(c).equals(need.get(c))) valid++;
        }
        while (valid == need.size()) {
            if (r - l < len) { len = r - l; start = l; }
            char d = s.charAt(l++);
            if (need.containsKey(d)) {
                if (win.get(d).equals(need.get(d))) valid--;
                win.merge(d, -1, Integer::sum);
            }
        }
    }
    return len == Integer.MAX_VALUE ? "" : s.substring(start, start + len);
}
易错：「包含所有字符」包含次数；要维护 valid 判断达标。

五、普通数组 Array

核心思想：数组题考查下标操作、原地修改、状态转移。

5.1 最大子数组和

找和最大的连续子数组。

核心：维护 cur 表示以当前位置结尾的最大和；cur=max(x,cur+x)；ans 记录最大 cur。

public int maxSubArray(int[] nums) {
    int cur = nums[0], ans = nums[0];
    for (int i = 1; i < nums.length; i++) {
        cur = Math.max(nums[i], cur + nums[i]);
        ans = Math.max(ans, cur);
    }
    return ans;
}
易错：全负数组答案是最大负数，不能初始化答案为 0。

5.2 合并区间

合并所有重叠区间。

核心：按左端点升序排序；当前左端点 ≤ 结果集最后右端点则重叠，更新右端点取最大值；否则加入新区间。

public int[][] merge(int[][] intervals) {
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
    List<int[]> res = new ArrayList<>();
    for (int[] iv : intervals) {
        if (!res.isEmpty() && iv[0] <= res.get(res.size()-1)[1])
            res.get(res.size()-1)[1] = Math.max(res.get(res.size()-1)[1], iv[1]);
        else res.add(iv);
    }
    return res.toArray(new int[0][]);
}
易错：Java 比较器建议 Integer.compare(a[0],b[0]) 避免减法溢出。

5.3 轮转数组

数组向右轮转 k 位，O(1) 额外空间。

核心（三次反转）：k=k%n；反转整个；反转前 k 个；反转后 n-k 个。

public void rotate(int[] nums, int k) {
    int n = nums.length; k %= n;
    reverse(nums, 0, n - 1);
    reverse(nums, 0, k - 1);
    reverse(nums, k, n - 1);
}
void reverse(int[] nums, int l, int r) {
    while (l < r) { int t = nums[l]; nums[l] = nums[r]; nums[r] = t; l++; r--; }
}
易错：必须先取模；右轮转和左轮转反转顺序不同。

5.4 除自身以外数组的乘积

answer[i] 等于除 nums[i] 外所有元素乘积，不能用除法，O(n)。

核心：正向遍历令 ans[i] 保存 i 左侧乘积；反向遍历用变量 right 保存右侧乘积，ans[i]*=right 后 right*=nums[i]。

public int[] productExceptSelf(int[] nums) {
    int n = nums.length, ans[] = new int[n], right = 1;
    ans[0] = 1;
    for (int i = 1; i < n; i++) ans[i] = ans[i - 1] * nums[i - 1];
    for (int i = n - 1; i >= 0; i--) { ans[i] *= right; right *= nums[i]; }
    return ans;
}
易错：不用除法因为可能有 0；左积右积初始都为 1。

5.5 缺失的第一个正数

找没出现的最小正整数，O(n) 时间 O(1) 空间。

核心（原地哈希）：长度 n 的数组答案只在 [1,n+1]；把值 x 放到下标 x-1 位置（只处理 1≤x≤n，while 不断交换）；第一个 nums[i]!=i+1 的位置答案是 i+1。

public int firstMissingPositive(int[] nums) {
    int n = nums.length;
    for (int i = 0; i < n; i++) {
        while (nums[i] >= 1 && nums[i] <= n && nums[i] != nums[nums[i] - 1]) {
            int t = nums[i]; nums[i] = nums[t - 1]; nums[t - 1] = t;
        }
    }
    for (int i = 0; i < n; i++) if (nums[i] != i + 1) return i + 1;
    return n + 1;
}
易错：交换条件要加 nums[i]!=nums[nums[i]-1] 避免死循环。

六、矩阵 Matrix

核心思想：矩阵题考查边界处理、原地标记、按层/按方向遍历。

6.1 矩阵置零

若 matrix[i][j]==0，把整行整列都置 0。

核心（原地标记）：先用两布尔变量记录第一行、第一列原本是否有 0；遍历非第一行第一列区域，遇到 0 就标记 matrix[i][0]=0 和 matrix[0][j]=0；再根据标记置零；最后根据布尔变量处理第一行第一列。

public void setZeroes(int[][] matrix) {
    int m = matrix.length, n = matrix[0].length;
    boolean firstRow0 = false, firstCol0 = false;
    for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRow0 = true;
    for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstCol0 = true;
    for (int i = 1; i < m; i++) for (int j = 1; j < n; j++)
        if (matrix[i][j] == 0) { matrix[i][0] = 0; matrix[0][j] = 0; }
    for (int i = 1; i < m; i++) for (int j = 1; j < n; j++)
        if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;
    if (firstRow0) for (int j = 0; j < n; j++) matrix[0][j] = 0;
    if (firstCol0) for (int i = 0; i < m; i++) matrix[i][0] = 0;
}
易错：第一行第一列既保存原始数据又作标记位，必须额外记录它们原本是否有 0；处理它们要放在最后。

6.2 螺旋矩阵

按顺时针螺旋顺序返回矩阵所有元素。

核心（四边界收缩）：u=0,d=m-1,l=0,r=n-1；按「右、下、左、上」遍历，每边走完立即收缩并检查交错（if(++u>d)break）。

public List<Integer> spiralOrder(int[][] matrix) {
    List<Integer> ans = new ArrayList<>();
    int u = 0, d = matrix.length - 1, l = 0, r = matrix[0].length - 1;
    while (true) {
        for (int j = l; j <= r; j++) ans.add(matrix[u][j]); if (++u > d) break;
        for (int i = u; i <= d; i++) ans.add(matrix[i][r]); if (--r < l) break;
        for (int j = r; j >= l; j--) ans.add(matrix[d][j]); if (--d < u) break;
        for (int i = d; i >= u; i--) ans.add(matrix[i][l]); if (++l > r) break;
    }
    return ans;
}
易错：每边遍历完必须立即检查边界并 break，防止单行/单列重复加入。

6.3 旋转图像

n×n 矩阵顺时针旋转 90 度，原地修改。

核心：沿主对角线转置（交换 matrix[i][j] 和 matrix[j][i]，只遍历 j>i）；再对每行左右反转。

public void rotate(int[][] matrix) {
    int n = matrix.length;
    for (int i = 0; i < n; i++) for (int j = i + 1; j < n; j++) {
        int t = matrix[i][j]; matrix[i][j] = matrix[j][i]; matrix[j][i] = t;
    }
    for (int[] row : matrix) {
        int l = 0, r = n - 1;
        while (l < r) { int t = row[l]; row[l] = row[r]; row[r] = t; l++; r--; }
    }
}
易错：顺时针 90°=转置+行反转；逆时针 90°=转置+列反转，别混淆。

6.4 搜索二维矩阵 II

每行每列升序，判断 target 是否存在。

核心：从右上角 (0,n-1) 开始；大于 target 向左移；小于 target 向下移；越界返回 false。

public boolean searchMatrix(int[][] matrix, int target) {
    int m = matrix.length, n = matrix[0].length;
    int i = 0, j = n - 1;
    while (i < m && j >= 0) {
        if (matrix[i][j] == target) return true;
        else if (matrix[i][j] > target) j--;
        else i++;
    }
    return false;
}
易错：右上角和左下角都可作起点；左上角或右下角无法一次排除一整行或一整列；时间 O(m+n)。

七、链表 Linked List

核心思想：链表题考查指针操作、虚拟头节点、快慢指针。改指针前先保存 next，删除头节点先想 dummy。

7.1 相交链表

两单链表是否相交，返回第一个相交节点。

核心：pA 从 headA 走到 null 转 headB；pB 从 headB 走到 null 转 headA；两指针都走 A长度+B长度，长度差被抵消。

public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode pA = headA, pB = headB;
    while (pA != pB) {
        pA = pA == null ? headB : pA.next;
        pB = pB == null ? headA : pB.next;
    }
    return pA;
}
易错：比较节点用引用相等 pA==pB，不是值相等。

7.2 反转链表

反转单链表，返回新头节点。

核心：prev=null,cur=head；先保存 next=cur.next，令 cur.next=prev，prev=cur，cur=next；返回 prev。

public ListNode reverseList(ListNode head) {
    ListNode prev = null, cur = head;
    while (cur != null) {
        ListNode next = cur.next;
        cur.next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}
易错：必须先保存 next 否则链表断开。

7.3 回文链表

判断链表前后读是否相同。

核心：快慢指针找中点；反转后半段；两指针分别从头部和后半段头部比较节点值。

public boolean isPalindrome(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; }
    ListNode p1 = head, p2 = reverse(slow);
    while (p2 != null) {
        if (p1.val != p2.val) return false;
        p1 = p1.next; p2 = p2.next;
    }
    return true;
}
易错：中点写法要和反转逻辑配套；反转后半段要返回新头节点。

7.4 环形链表 / 环形链表 II

判断是否有环 / 返回入环节点。

核心（II）：第一阶段快指针一次两步、慢指针一次一步，相遇则有环；第二阶段把一个指针放回头节点，两个都改一次一步，再次相遇位置即入环点。

public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next; fast = fast.next.next;
        if (slow == fast) {
            ListNode p = head;
            while (p != slow) { p = p.next; slow = slow.next; }
            return p;
        }
    }
    return null;
}
易错：循环条件 fast!=null && fast.next!=null；返回的是节点对象不是下标。

7.5 合并两个有序链表 / 两数相加

合并：两升序链表合并为新升序链表。两数相加：两逆序数字链表相加。

合并核心：建 dummy 和 cur；比较两链表当前节点值，小者接到 cur.next；循环结束接上剩余链表。

两数相加核心：建 dummy 和 cur，维护进位 carry；当 l1、l2 或 carry 任一存在时循环；当前和 x+y+carry，新节点值 sum%10，新进位 sum/10。

public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0), cur = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { cur.next = l1; l1 = l1.next; }
        else { cur.next = l2; l2 = l2.next; }
        cur = cur.next;
    }
    cur.next = l1 != null ? l1 : l2;
    return dummy.next;
}
易错：dummy 统一处理头节点变化；最后还有进位要新建节点。

7.6 删除链表的倒数第 N 个结点

删除倒数第 n 个节点。

核心：建 dummy.next=head；快慢指针都从 dummy 出发；快指针先走 n 步；快慢一起走到快指针到最后一个节点；此时慢指针在待删除节点前一个位置；slow.next=slow.next.next。

public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0, head), fast = dummy, slow = dummy;
    for (int i = 0; i < n; i++) fast = fast.next;
    while (fast.next != null) { fast = fast.next; slow = slow.next; }
    slow.next = slow.next.next;
    return dummy.next;
}
易错：dummy 处理删除头节点的情况。

7.7 两两交换链表中的节点 / K 个一组翻转

两两交换：相邻节点两两交换。K 个一组：每 k 个节点一组翻转，不足 k 保持原样。

两两交换核心：建 dummy 指向 head；prev 指向每组两节点之前的位置；当 prev.next 和 prev.next.next 都不为空时，记录 node1=prev.next、node2=node1.next，调整 prev.next=node2、node1.next=node2.next、node2.next=node1；prev=node1。

K 个一组核心：每次从 groupPrev 向后找第 k 个节点；不足 k 结束；记录下一组起点 groupNext；翻转 [groupPrev.next,kth]；重新连接；groupPrev 移到本组翻转后尾部。

public ListNode swapPairs(ListNode head) {
    ListNode dummy = new ListNode(0, head), prev = dummy;
    while (prev.next != null && prev.next.next != null) {
        ListNode n1 = prev.next, n2 = n1.next;
        prev.next = n2; n1.next = n2.next; n2.next = n1;
        prev = n1;
    }
    return dummy.next;
}
易错：不能只交换值；不足 k 个不能翻转；翻转局部链表前要保存下一组起点。

7.8 随机链表的复制

带 next 和 random 指针的链表深拷贝。

核心（哈希映射法）：第一遍为每个原节点创建新节点存入 Map<原节点,新节点>；第二遍利用 map 设置 copyNode.next=map.get(cur.next)、copyNode.random=map.get(cur.random)；返回 map.get(head)。

原地拼接法：每个原节点后插入拷贝；复制 random（cur.next.random=cur.random.next）；拆分链表。空间 O(1)。

public Node copyRandomList(Node head) {
    if (head == null) return null;
    Map<Node,Node> map = new HashMap<>();
    for (Node cur = head; cur != null; cur = cur.next)
        map.put(cur, new Node(cur.val));
    for (Node cur = head; cur != null; cur = cur.next) {
        map.get(cur).next = map.get(cur.next);
        map.get(cur).random = map.get(cur.random);
    }
    return map.get(head);
}

7.9 排序链表

链表升序排序，O(n log n)。

核心（递归归并）：快慢指针找前半段尾节点（fast=head.next 让 slow 停在前半段尾部）；right=slow.next，slow.next=null 断链；递归排序左右半段；合并两个有序链表。

public ListNode sortList(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode slow = head, fast = head.next;
    while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; }
    ListNode right = slow.next; slow.next = null;
    return merge(sortList(head), sortList(right));
}
易错：断链 slow.next=null 必不可少；合并剩余链表写 cur.next=left 不是 cur=left；递归版空间 O(log n)。

8.1 二叉树的中序遍历

返回中序遍历结果（左、根、右）。

核心（迭代）：用栈；当前节点不为空时一路向左压栈；弹出节点并访问；转向右子树。外层条件 cur!=null || !stack.isEmpty()。

public List<Integer> inorderTraversal(TreeNode root) {
    List<Integer> ans = new ArrayList<>();
    Deque<TreeNode> stack = new LinkedList<>();
    TreeNode cur = root;
    while (cur != null || !stack.isEmpty()) {
        while (cur != null) { stack.push(cur); cur = cur.left; }
        cur = stack.pop(); ans.add(cur.val); cur = cur.right;
    }
    return ans;
}
BST 的中序遍历是严格递增序列，是很多 BST 题的基础。

8.2 二叉树的最大深度

根节点到最远叶子节点路径上的节点数。

核心：节点为空深度 0；递归求左右子树深度；当前深度 max(left,right)+1。典型后序遍历。

public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
}
易错：返回的是节点数不是边数。

8.3 翻转二叉树 / 对称二叉树

翻转：交换每个节点左右子树。对称：判断是否关于中心轴镜像对称。

翻转核心：节点为空返回 null；交换当前节点 left 和 right；递归翻转左右子树。

对称核心：辅助函数 check(left,right)；两节点都为空返回 true；只有一个为空返回 false；值不同返回 false；递归比较 left.left 和 right.right、left.right 和 right.left。

public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode t = root.left; root.left = root.right; root.right = t;
    invertTree(root.left); invertTree(root.right);
    return root;
}
易错：对称比较的是两棵子树是否镜像，不是单棵树自己左右是否相等。

8.4 二叉树的直径 / 二叉树中的最大路径和

直径：任意两节点间最长路径长度（按边数）。最大路径和：任意路径的最大节点值之和。

直径核心：后序遍历求每节点最大深度；经过它的最长路径为 左深度+右深度；全局变量 ans 维护最大直径；向父节点返回 max(leftDepth,rightDepth)+1。

最大路径和核心：后序遍历；对每节点先计算左右子树向上能贡献的最大路径和；某边贡献小于 0 丢弃按 0 算；经过当前节点的最大路径和为 node.val+leftGain+rightGain；向父节点只能返回一条路径 node.val+max(leftGain,rightGain)。

int ans = 1;
public int diameterOfBinaryTree(TreeNode root) {
    depth(root);
    return ans - 1;
}
int depth(TreeNode node) {
    if (node == null) return 0;
    int l = depth(node.left), r = depth(node.right);
    ans = Math.max(ans, l + r + 1);
    return Math.max(l, r) + 1;
}
易错：最大路径不一定经过根节点，必须遍历每个节点；最大路径和的全局答案初始化不能是 0（树可能全负数）。

8.5 二叉树的层序遍历 / 二叉树的右视图

层序：按层从左到右返回节点值，每层单独列表。右视图：每层只返回最右节点。

层序核心：根节点入队；队列不为空时先记录当前层节点数 size；循环 size 次依次出队加入当前层列表；出队节点左右孩子入队。

右视图 DFS：按「根→右→左」顺序递归；depth==ans.size() 说明第一次到达这一层，此时看到的一定是最右节点。

public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> ans = new ArrayList<>();
    if (root == null) return ans;
    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int size = q.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode n = q.poll();
            level.add(n.val);
            if (n.left != null) q.offer(n.left);
            if (n.right != null) q.offer(n.right);
        }
        ans.add(level);
    }
    return ans;
}
易错：层序每层开始前必须固定 size；右视图不是只沿右指针走，某些层右视图节点可能来自左子树。

8.6 将有序数组转换为二叉搜索树 / 验证 BST / 第 K 小

有序数组转 BST：升序数组转高度平衡 BST。验证 BST：判断是否有效 BST。第 K 小：BST 中第 k 小的节点值。

有序数组转 BST：递归处理区间 [l,r]；l>r 返回 null；取中点 mid=l+(r-l)/2 作根节点；左右半区间构建左右子树。

验证 BST（中序）：中序遍历维护上一个访问节点值 pre；当前值 <=pre 返回 false。BST 要求严格小于和严格大于。上下界建议用 long 避免 Integer.MIN_VALUE 边界出错。

第 K 小：利用 BST 中序遍历递增性质；按中序遍历访问节点，每访问一个 count++；count==k 时当前节点即答案。

public TreeNode sortedArrayToBST(int[] nums) {
    return build(nums, 0, nums.length - 1);
}
TreeNode build(int[] nums, int l, int r) {
    if (l > r) return null;
    int mid = l + (r - l) / 2;
    TreeNode root = new TreeNode(nums[mid]);
    root.left = build(nums, l, mid - 1);
    root.right = build(nums, mid + 1, r);
    return root;
}
易错：取中点用 l+(r-l)/2；k 从 1 开始不是从 0。

8.7 二叉树展开为链表

原地展开为单链表（用 right 指针，left 全置 null），顺序与前序遍历一致。

核心（递归后序）：递归展开左子树；递归展开右子树；保存原右子树 rightSubtree；将左子树移到右子树位置 root.right=root.left；root.left=null；沿新右链走到末尾；把原右子树接到末尾。

public void flatten(TreeNode root) {
    if (root == null) return;
    flatten(root.left);
    flatten(root.right);
    TreeNode right = root.right;
    root.right = root.left;
    root.left = null;
    TreeNode cur = root;
    while (cur.right != null) cur = cur.right;
    cur.right = right;
}
易错：修改指针前必须先保存原右子树否则丢失节点；展开后所有 left 必须为 null。

8.8 从前序与中序遍历序列构造二叉树

根据前序和中序还原二叉树，节点值不重复。

核心：前序第一个元素是当前子树根节点；在中序中找到根节点位置，左边是左子树、右边是右子树；根据左子树长度切分前序的左右子树范围；递归构建。优化：用 HashMap 记录 中序值→下标，递归传数组边界不复制数组。

Map<Integer,Integer> map;
public TreeNode buildTree(int[] pre, int[] in) {
    map = new HashMap<>();
    for (int i = 0; i < in.length; i++) map.put(in[i], i);
    return build(pre, 0, pre.length - 1, 0);
}
TreeNode build(int[] pre, int l, int r, int inL) {
    if (l > r) return null;
    int rootVal = pre[l], idx = map.get(rootVal), leftSize = idx - inL;
    TreeNode root = new TreeNode(rootVal);
    root.left = build(pre, l + 1, l + leftSize, inL);
    root.right = build(pre, l + leftSize + 1, r, idx + 1);
    return root;
}
易错：递归边界要统一（常用闭区间 [l,r]）；不要在每层递归创建新数组。

8.9 路径总和 III

路径不必从根开始也不必到叶子，但必须向下；返回路径和等于 targetSum 的路径数量。

核心（前缀和）：从根 DFS 维护路径前缀和 curSum；若存在之前前缀和 curSum-targetSum，说明从那个位置之后到当前节点的路径和为 target；HashMap 记录每个前缀和出现次数；进入当前节点时把当前前缀和加入 map；回溯离开时把当前前缀和次数减 1。初始化 map.put(0L,1)。

int ans = 0;
public int pathSum(TreeNode root, int targetSum) {
    Map<Long,Integer> map = new HashMap<>();
    map.put(0L, 1);
    dfs(root, 0L, targetSum, map);
    return ans;
}
void dfs(TreeNode node, long cur, int target, Map<Long,Integer> map) {
    if (node == null) return;
    cur += node.val;
    if (map.containsKey(cur - target)) ans += map.get(cur - target);
    map.merge(cur, 1, Integer::sum);
    dfs(node.left, cur, target, map);
    dfs(node.right, cur, target, map);
    map.merge(cur, -1, Integer::sum);
}
易错：路径必须向下不能从子节点走回父节点；前缀和建议用 long；回溯时必须撤销当前前缀和（Map 这类共享对象递归结束时必须恢复，long sum 基本类型每层递归有自己的副本不需要手动撤销）。

8.10 二叉树的最近公共祖先

普通二叉树（非 BST）的 p 和 q 的最近公共祖先。一个节点可以是自己的祖先。

核心（递归）：节点为空返回 null；当前节点等于 p 或 q 直接返回当前节点；递归搜索左右子树得 left 和 right；left 和 right 都不为空说明 p 和 q 分布在两侧，当前节点即最近公共祖先；只有一边不为空返回不为空那边。

父指针 + 哈希表写法：先 DFS 建立 当前节点→父节点 映射；从 q 一路向上把路径上所有节点加入 HashSet（包括 q 自己）；从 p 一路向上，第一个出现在集合中的节点即答案。

public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) return root;
    return left != null ? left : right;
}
易错：普通二叉树不能用大小关系判断方向；比较的是节点对象引用不是节点值；要把 q 自己也加入集合。

九、图论 / Trie

9.2 腐烂的橘子（L994）

核心（多源 BFS）：遍历网格把所有初始腐烂橘子加入队列，同时统计新鲜橘子数量 fresh；BFS 按层扩散每层代表一分钟；每感染一个改成 2、fresh--、加入队列；BFS 结束后 fresh==0 返回时间，否则返回 -1。

public int orangesRotting(int[][] grid) {
    int m = grid.length, n = grid[0].length, fresh = 0, time = 0;
    Queue<int[]> q = new LinkedList<>();
    for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
        if (grid[i][j] == 2) q.offer(new int[]{i, j});
        if (grid[i][j] == 1) fresh++;
    }
    int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};
    while (!q.isEmpty() && fresh > 0) {
        for (int size = q.size(); size > 0; size--) {
            int[] p = q.poll();
            for (int[] d : dirs) {
                int x = p[0]+d[0], y = p[1]+d[1];
                if (x >= 0 && x < m && y >= 0 && y < n && grid[x][y] == 1) {
                    grid[x][y] = 2; fresh--; q.offer(new int[]{x, y});
                }
            }
        }
        time++;
    }
    return fresh == 0 ? time : -1;
}

10.1 全排列（L46）

不含重复数字的数组，返回所有可能排列。

10.2 子集（L78）

元素互不相同的整数数组，返回所有可能子集（幂集）。

核心（枚举起点）：每进入一层递归都先把当前 path 加入答案；从 start 开始枚举可选元素；选 nums[i] 后进入下一层从 i+1 开始；递归结束后撤销选择。

方法二（二进制位图）：长度 n 的数组有 2^n 个子集；外层循环 0 到 (1<<n)-1，内层检查第 j 位是否为 1（(i>>j)&1==1），是则把 nums[j] 加入子集。仅适用于 n 较小（≤10）。

void dfs(int[] nums, int start, List<Integer> path, List<List<Integer>> ans) {
    ans.add(new ArrayList<>(path));          // 进入每层都先收集
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        dfs(nums, i + 1, path, ans);             // 下一层从 i+1 开始
        path.remove(path.size() - 1);
    }
}
易错：i+1 是避免重复选择同一元素的关键；位图法 1<<n 当 n>31 会溢出。

10.4 组合总和（L39）

核心：path 保存当前组合；remain 表示还差多少；从 start 开始枚举候选数字；选 candidates[i] 后下一层仍从 i 开始（数字可重复使用）；remain==0 收集答案；remain<0 停止当前分支。

void dfs(int[] candidates, int start, int remain, List<Integer> path, List<List<Integer>> ans) {
    if (remain == 0) { ans.add(new ArrayList<>(path)); return; }
    for (int i = start; i < candidates.length; i++) {
        if (candidates[i] > remain) break;        // 剪枝（需先排序）
        path.add(candidates[i]);
        dfs(candidates, i, remain - candidates[i], path, ans);  // 传 i 不是 i+1
        path.remove(path.size() - 1);
    }
}

易错：「重复使用」指同一数字可在 path 出现多次（递归传 i 不是 i+1）；「重复组合」指集合内容相同但顺序不同（靠 start 控制）。

10.6 单词搜索（L79）

核心：遍历矩阵每个位置尝试作起点；DFS 参数含当前位置 (r,c) 和当前匹配到的字符下标 index；越界、已访问、字符不匹配返回 false；index==word.length()-1 且当前字符匹配返回 true；标记当前位置已访问；向上下左右递归搜索下一个字符；搜索结束后恢复当前位置未访问。

boolean dfs(char[][] board, int r, int c, String word, int idx, boolean[][] visited) {

    if (idx == word.length() - 1) return true;
    visited[r][c] = true;
    int[] dr = {-1, 1, 0, 0}, dc = {0, 0, -1, 1};

11.1 搜索插入位置（L35）

升序数组和 target，存在返回下标，不存在返回应插入位置，O(log n)。

核心：找第一个大于等于 target 的位置；l=0,r=nums.length 左闭右开；l<r 时取 mid；nums[mid]>=target 则 r=mid，否则 l=mid+1；返回 l。本质是 lower_bound。

int searchInsert(int[] nums, int target) {
    int l = 0, r = nums.length;       // 左闭右开 [l, r)
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] >= target) r = mid;     // 找第一个 >= target
        else l = mid + 1;
    }
    return l;                          // l 即插入位置
}
易错：返回位置可能等于 nums.length 表示插入到最后。

11.2 搜索二维矩阵（L74）

每行升序，每行第一个大于前一行的最后一个整数，判断 target 是否存在。

方法一（逐行二分）：对每一行执行标准一维二分。时间 O(m log n)。

方法二（两次二分）：第一次对第一列二分找「最后一个小于等于 target 的行索引 row」（用 high 接住）；第二次在该行内执行标准二分。时间 O(log m+log n)=O(log(mn))。

boolean searchMatrix(int[][] matrix, int target) {
    int m = matrix.length, n = matrix[0].length;
    int l = 0, r = m - 1, row = -1;       // 第一次二分找最后一个 ≤ target 的行
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (matrix[mid][0] <= target) { row = mid; l = mid + 1; } else r = mid - 1;
    }
    if (row < 0) return false;
    int lo = 0, hi = n - 1;               // 第二次二分在该行内找
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (matrix[row][mid] == target) return true;
        if (matrix[row][mid] < target) lo = mid + 1; else hi = mid - 1;
    }
    return false;
}
易错：第一次二分定位行时若 target 比第一行第一个元素还小直接返回 false；row=high 此时 high 指向最后一个 ≤ target 的位置。

11.3 在排序数组中查找元素的第一个和最后一个位置（L34）

非递减数组和 target，找开始和结束位置，不存在返回 [-1,-1]，O(log n)。

核心：第一次二分找左边界（第一个 >=target 的位置）；若左边界越界或 nums[left]!=target 返回 [-1,-1]；第二次二分找右边界（最后一个 <=target 的位置）。

int[] searchRange(int[] nums, int target) {
    int l = lowerBound(nums, target);                  // 第一个 >= target
    if (l == nums.length || nums[l] != target) return new int[]{-1, -1};
    int r = upperBound(nums, target) - 1;               // 最后一个 <= target
    return new int[]{l, r};
}
int lowerBound(int[] a, int t) { int l = 0, r = a.length; while (l < r) { int m = l + (r - l) / 2; if (a[m] >= t) r = m; else l = m + 1; } return l; }
int upperBound(int[] a, int t) { int l = 0, r = a.length; while (l < r) { int m = l + (r - l) / 2; if (a[m] > t) r = m; else l = m + 1; } return l; }
易错：找左边界用 mid=l+(r-l)/2；找右边界若写 l=mid 要用右中位数 mid=l+(r-l+1)/2 避免死循环；两次二分的边界模板不要混用。

11.4 搜索旋转排序数组（L33）

升序数组在未知位置旋转，元素互不相同，找 target 返回下标，O(log n)。

核心分析：旋转数组无论从哪里切成两半，至少有一半一定依然有序。通过 nums[left]<=nums[mid] 判断左半边有序，否则右半边有序。在有序区间内判断 target 是否落在范围内来决定收缩方向。

int search(int[] nums, int target) {
    int l = 0, r = nums.length - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] == target) return mid;
        if (nums[l] <= nums[mid]) {                       // 左半有序
            if (nums[l] <= target && target < nums[mid]) r = mid - 1; else l = mid + 1;
        } else {                                          // 右半有序
            if (nums[mid] < target && target <= nums[r]) l = mid + 1; else r = mid - 1;
        }
    }
    return -1;
}
易错：nums[left]<=nums[mid] 的等号很重要处理 left==mid 的情况；本题前提是无重复元素，若允许重复（L81）当 nums[left]==nums[mid] 时无法判断哪边有序需 left++，最坏退化 O(n)。

11.5 寻找旋转排序数组中的最小值（L153）

升序数组旋转后元素互不相同，找最小元素，O(log n)。

核心：二分比较 nums[mid] 和 nums[r]；nums[mid]>nums[r] 说明 mid 在左侧高位区，最小值在右半边 l=mid+1；否则 mid 在右侧低位区，最小值在 mid 或左边 r=mid；l==r 时返回 nums[l]。

int findMin(int[] nums) {
    int l = 0, r = nums.length - 1;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] > nums[r]) l = mid + 1;   // mid 在左高位区，最小在右
        else r = mid;                            // mid 在右低位区，最小在 mid 或左
    }
    return nums[l];
}
属性边界思维：定义属性「元素是否小于等于数组最右侧元素」。旋转点左侧都大于 nums[n-1]，旋转点及右侧都小于等于 nums[n-1]。最小值就是第一个满足此属性的元素。这种「寻找属性转折点」的思维是解决复杂二分问题的利器。
易错：比较 nums[mid] 和右端点比左端点更稳定（即使数组没旋转也能正确收缩）；若有重复（L154）需 r-- 线性缩小。

11.6 寻找两个正序数组的中位数（L4，困难）

两正序数组找合并后中位数，O(log(m+n))。

核心（找第 k 小）：总长度奇数找第 (m+n)/2+1 小；偶数找第 (m+n)/2 小和第 (m+n)/2+1 小的平均值；写函数 getKth(nums1,start1,nums2,start2,k)；每次比较两数组从当前起点往后第 k/2 个元素，较小的一边前 k/2 个元素不可能是第 k 小可整体丢弃；更新起点和 k 直到 k 为 1 或某数组用完。

double findMedianSortedArrays(int[] A, int[] B) {
    int total = A.length + B.length;
    if ((total & 1) == 1) return getKth(A, 0, B, 0, total / 2 + 1);
    return (getKth(A, 0, B, 0, total / 2) + getKth(A, 0, B, 0, total / 2 + 1)) / 2.0;
}
int getKth(int[] A, int i, int[] B, int j, int k) {
    if (A.length - i > B.length - j) return getKth(B, j, A, i, k);   // 保证 A 较短
    if (i == A.length) return B[j + k - 1];
    if (k == 1) return Math.min(A[i], B[j]);
    int pa = Math.min(i + k / 2, A.length), pb = j + (k - (pa - i));
    if (A[pa - 1] < B[pb - 1]) return getKth(A, pa, B, j, k - (pa - i));
    else return getKth(A, i, B, pb, k - (pb - j));
}
易错：k 从 1 开始计数不是下标；某数组剩余长度不足 k/2 时取它最后一个元素比较；返回偶数长度中位数时要转 double 避免整数除法。

十二、栈 Stack

核心思想：栈是「后进先出」的现场保存器。看到「括号嵌套、保存现场、下一个更大/更小」先想栈。

12.1 有效的括号（L20）

只含 ()[]{} 的字符串，判断括号是否有效。

核心：栈保存等待匹配的左括号；遇左括号入栈；遇右括号检查栈是否为空，栈顶左括号和当前右括号不匹配返回 false，匹配则弹栈；遍历结束后栈为空才有效。

boolean isValid(String s) {
    Deque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') st.push(')'); else if (c == '[') st.push(']'); else if (c == '{') st.push('}');
        else if (st.isEmpty() || st.pop() != c) return false;
    }
    return st.isEmpty();
}
易错：右括号到来时栈为空直接 false；最后栈不为空也 false。

12.2 最小栈（L155）

设计栈支持 push、pop、top，并能在常数时间返回栈中最小元素。

核心：普通栈保存所有元素；辅助栈保存当前最小值；push(val) 时若辅助栈空或 val<=minStack.peek() 辅助栈也入栈；pop() 时若弹出值等于辅助栈栈顶，辅助栈也弹出。

Deque<Integer> data = new ArrayDeque<>(), min = new ArrayDeque<>();
void push(int x) { data.push(x); if (min.isEmpty() || x <= min.peek()) min.push(x); }
void pop() { if (data.pop().equals(min.peek())) min.pop(); }
int top() { return data.peek(); }
int getMin() { return min.peek(); }
易错：辅助栈入栈条件用 <= 处理重复最小值。

12.3 每日温度（L739）

整数数组表示每天温度，对每天返回还要等多少天才出现更高温度，没有则 0。

核心（单调栈）：栈保存下标，对应温度单调递减；遍历每天 i；当当前温度大于栈顶下标对应温度时，说明找到栈顶那天的下一个更高温度；弹出栈顶 idx，答案为 i-idx；当前下标入栈。

int[] dailyTemperatures(int[] T) {
    int n = T.length; int[] ans = new int[n];
    Deque<Integer> st = new ArrayDeque<>();
    for (int i = 0; i < n; i++) {
        while (!st.isEmpty() && T[i] > T[st.peek()]) {
            int idx = st.pop(); ans[idx] = i - idx;
        }
        st.push(i);
    }
    return ans;
}
易错：栈中存下标不存温度因为答案需要天数差。

12.4 柱状图中最大的矩形（L84，困难）

非负整数数组 heights，每元素表示宽度为 1 的柱子高度，找最大矩形面积。

核心（单调递增栈）：栈保存柱子下标；遍历每个位置，当当前高度小于栈顶高度时栈顶柱子的右边界确定；弹出栈顶令它作矩形高度；弹出后新栈顶是它左边第一个更矮柱子；宽度为 right-left-1；可在数组左右加高度 0 的哨兵统一处理边界。

int largestRectangleArea(int[] heights) {
    int n = heights.length; int[] h = new int[n + 2];
    System.arraycopy(heights, 0, h, 1, n);          // 左右哨兵 0
    Deque<Integer> st = new ArrayDeque<>(); int ans = 0;
    for (int i = 0; i < h.length; i++) {
        while (!st.isEmpty() && h[i] < h[st.peek()]) {
            int height = h[st.pop()]; int left = st.isEmpty() ? -1 : st.peek();
            ans = Math.max(ans, height * (i - left - 1));
        }
        st.push(i);
    }
    return ans;
}
易错：本题核心是为每根柱子找到左右第一个比它矮的位置；加哨兵可避免最后手动清空栈。

12.5 字符串解码

编码字符串 k[encoded_string] 表示括号内字符串重复 k 次，可嵌套，返回解码后字符串。

核心：numStack 保存进入括号前的重复次数；strStack 保存进入括号前已构造好的字符串；遇数字累积 multi=multi*10+digit 处理多位数；遇 [ 保存当前 multi 和 cur 然后重置；遇字母追加到 cur；遇 ] 弹出重复次数和上一层字符串，把当前字符串重复拼接回上一层。

String decodeString(String s) {
    Deque<Integer> numSt = new ArrayDeque<>(); Deque<String> strSt = new ArrayDeque<>();
    int multi = 0; StringBuilder cur = new StringBuilder();
    for (char c : s.toCharArray()) {
        if (Character.isDigit(c)) multi = multi * 10 + c - '0';
        else if (c == '[') { numSt.push(multi); strSt.push(cur.toString()); multi = 0; cur = new StringBuilder(); }
        else if (c == ']') { int k = numSt.pop(); String prev = strSt.pop(); for (int i = 0; i < k; i++) prev += cur; cur = new StringBuilder(prev); }
        else cur.append(c);
    }
    return cur.toString();
}
易错：栈保存的是「进入括号前的现场」右括号负责恢复现场；数字可能是多位数不能只处理单个字符。

十三、堆 Heap

核心思想：堆是「动态维护最值」的工具。看到「前 K 个、动态最值、中位数」先想堆。

13.1 数组中的第 K 个最大元素（L215）

整数数组和 k，返回第 k 大元素（排序后第 k 大，不是第 k 个不同值）。

方法一（小顶堆）：创建容量最多为 k 的小顶堆；遍历数组把元素加入堆；堆大小超过 k 就弹出堆顶最小值；遍历结束堆顶即第 k 大。复杂度 O(n log k)。

方法二（快速选择）：第 k 大等价于排序后下标 n-k；使用快速选择 partition；每次只递归目标下标所在的一边。平均 O(n)。

// 方法一：小顶堆
int findKthLargest(int[] nums, int k) {
    PriorityQueue<Integer> pq = new PriorityQueue<>();   // 默认小顶堆
    for (int x : nums) {
        pq.offer(x);
        if (pq.size() > k) pq.poll();        // 维护容量 k，弹出最小的
    }
    return pq.peek();
}
易错：「第 k 大」不是「第 k 个不同值」；Java 中 PriorityQueue 默认是小顶堆。

13.2 前 K 个高频元素（L347）

整数数组和 k，返回出现频率最高的 k 个元素，顺序不限。

核心：哈希表统计每个数字出现次数；小顶堆按频率排序；遍历哈希表每个数字；把数字加入堆，堆大小超过 k 弹出频率最低的元素；最后堆中剩下的就是前 k 高频元素。

int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int x : nums) freq.merge(x, 1, Integer::sum);
    PriorityQueue<Integer> pq = new PriorityQueue<>((a, b) -> freq.get(a) - freq.get(b));
    for (int num : freq.keySet()) {
        pq.offer(num);
        if (pq.size() > k) pq.poll();
    }
    int[] ans = new int[k];
    for (int i = 0; i < k; i++) ans[i] = pq.poll();
    return ans;
}

13.3 数据流的中位数（L295，困难）

设计数据结构支持 addNum(num) 不断添加数字，并能随时返回当前所有数字的中位数。

核心（双堆）：大顶堆 small 保存较小的一半；小顶堆 large 保存较大的一半；插入数字时根据大小放入合适堆；调整两堆大小使它们大小差不超过 1；总数奇数中位数是元素更多的那个堆的堆顶；总数偶数中位数是两堆顶的平均值。

PriorityQueue<Integer> small = new PriorityQueue<>((a, b) -> Integer.compare(b, a)); // 大顶堆
PriorityQueue<Integer> large = new PriorityQueue<>();                              // 小顶堆
void addNum(int num) {
    if (small.isEmpty() || num <= small.peek()) small.offer(num); else large.offer(num);
    // 平衡：small 元素数 ∈ {large.size(), large.size()+1}
    if (small.size() > large.size() + 1) large.offer(small.poll());
    if (large.size() > small.size()) small.offer(large.poll());
}
double findMedian() {
    return small.size() > large.size() ? small.peek() : (small.peek() + large.peek()) / 2.0;
}
易错：大顶堆可用 PriorityQueue<>((a,b)->b-a) 但为避免溢出建议用 Integer.compare(b,a)；要同时维护大小平衡和顺序关系（大顶堆所有元素 ≤ 小顶堆所有元素）；平均值要返回 double。

十四、贪心算法 Greedy

核心思想：每一步维护当前能到达的最优边界，不回溯。看到「每一步局部最优能推出全局最优」先想贪心。

14.1 买卖股票的最佳时机（L121）

prices[i] 表示第 i 天股票价格，只能选一天买入、之后某天卖出，最多一笔交易，返回最大利润。

核心：维护历史最低买入价 minPrice；从左到右遍历每天价格；假设今天卖出利润为 prices[i]-minPrice；用该利润更新最大答案；再用当前价格更新 minPrice。

int maxProfit(int[] prices) {
    int minPrice = Integer.MAX_VALUE, ans = 0;
    for (int p : prices) {
        ans = Math.max(ans, p - minPrice);   // 今天卖出的利润
        minPrice = Math.min(minPrice, p);    // 更新历史最低买入价
    }
    return ans;
}
易错：必须先买后卖所以只能用当前天之前的最低价；价格一直下降答案为 0；只能交易一次不能累计多个上涨区间。

14.2 跳跃游戏（L55）

非负整数数组，每元素表示从该位置最多可跳长度，初始在下标 0，判断能否到达最后一个下标。

核心：维护当前能到达的最远位置 farthest；从左到右遍历下标 i；i>farthest 说明当前位置不可达返回 false；否则更新 farthest=max(farthest,i+nums[i])；farthest>=n-1 返回 true。

boolean canJump(int[] nums) {
    int farthest = 0;
    for (int i = 0; i < nums.length; i++) {
        if (i > farthest) return false;          // 当前位置不可达
        farthest = Math.max(farthest, i + nums[i]);
        if (farthest >= nums.length - 1) return true;
    }
    return true;
}
易错：只关心能到达的最远位置不需要真的模拟每种跳法；nums[i] 表示最多跳不是必须跳这么远。

14.3 跳跃游戏 II（L45）

非负整数数组，每元素表示可跳最大长度，假设总能到达最后位置，返回最少跳跃次数。

核心（基于区间的贪心）：维护「当前跳跃步数能覆盖的区间 [l,r]」；count=0,l=0,r=0,longest=0；只要 longest 还没到末尾：在 [l,r] 内计算下一步能跳到的最远位置 longest=max(longest,i+nums[i])；count++；更新下一跳区间 l=r+1,r=longest。

int jump(int[] nums) {
    int count = 0, l = 0, r = 0, longest = 0, n = nums.length;
    while (longest < n - 1) {
        for (int i = l; i <= r; i++) longest = Math.max(longest, i + nums[i]);
        count++; l = r + 1; r = longest;
    }
    return count;
}
分级思想：这种解法本质把跳跃过程看作「分层」。第 0 层是下标 [0,0] 跳 0 次；第 1 层是下标 [1,nums[0]] 跳 1 次；第 2 层是从第 1 层所有位置中能跳到的最远范围。每一跳都尽量覆盖最远范围保证用最少跳跃次数覆盖到终点。

14.4 划分字母区间（L763）

字符串 s 划分为尽可能多片段，使每个字母最多只出现在一个片段，返回每片段长度。

核心：先遍历字符串记录每个字符最后一次出现的位置；再从左到右扫描；start 表示当前片段起点，end 表示当前片段必须覆盖到的最远位置；每看到一个字符就更新 end=max(end,last[char])；i==end 时说明当前片段中所有字符都不会出现在后面可以切分；加入长度 end-start+1，更新 start=i+1。

List<Integer> partitionLabels(String s) {
    int[] last = new int[26];
    for (int i = 0; i < s.length(); i++) last[s.charAt(i) - 'a'] = i;
    List<Integer> ans = new ArrayList<>();
    int start = 0, end = 0;
    for (int i = 0; i < s.length(); i++) {
        end = Math.max(end, last[s.charAt(i) - 'a']);
        if (i == end) { ans.add(end - start + 1); start = i + 1; }
    }
    return ans;
}
易错：关键是先知道每个字符的最后出现位置；i==end 时才能切不能只看当前字符。

十五、技巧 Skills

核心思想：位运算、摩尔投票、荷兰国旗、快慢指针是常见压轴模板。看到「线性时间 + 常数空间」的特殊约束先想这些技巧。

15.1 只出现一次的数字（L136）

非空整数数组，除某元素只出现一次外其余都出现两次，找那个只出现一次的元素，线性时间且不使用额外空间。

核心：异或运算；初始化 ans=0；遍历数组执行 ans^=nums[i]；最后 ans 就是只出现一次的数字。

int singleNumber(int[] nums) {
    int ans = 0;
    for (int x : nums) ans ^= x;     // 成对数字异或为 0，剩下只出现一次的
    return ans;
}
异或性质：a^a=0，a^0=a，满足交换律和结合律，所以成对数字会抵消。

15.2 多数元素（L169）

大小 n 的数组，返回出现次数大于 ⌊n/2⌋ 的元素，题目保证多数元素一定存在。

方法一（摩尔投票法）：设候选人 candidate=null，票数 count=0；遍历数组：count==0 时把当前元素设为 candidate；当前元素等于 candidate 则 count++，否则 count--（互相抵消）；遍历结束 candidate 即所求。由于多数元素次数大于 n/2，即使和其他所有元素一一抵消最后剩下的依然是它。时间 O(n) 空间 O(1)。

方法二（排序法）：数组排序后返回下标为 n/2 的元素。如果一个数字出现次数超过一半，在排序后的数组中必然会覆盖到中点位置。时间 O(n log n)。

// 方法一：摩尔投票法
int majorityElement(int[] nums) {
    int candidate = 0, count = 0;
    for (int x : nums) {
        if (count == 0) candidate = x;
        count += (x == candidate) ? 1 : -1;     // 互相抵消
    }
    return candidate;
}
易错：题目保证存在所以摩尔投票法不需要结束后再遍历验证；面试首选摩尔投票法空间 O(1)。

15.3 颜色分类（L75）

包含红白蓝（用 0、1、2 表示）的数组，原地排序使相同颜色相邻并按红白蓝顺序，不能用库函数排序。

方法一（荷兰国旗算法，三指针一趟遍历）：p0 指向 0 的右边界（初始 0），p2 指向 2 的左边界（初始 n-1），i 为当前扫描指针；遍历直到 i>p2：nums[i]==0 交换 nums[i] 和 nums[p0] 后 p0++、i++；nums[i]==2 交换 nums[i] 和 nums[p2] 后 p2--（i 不动因为换回来的数还没检查）；nums[i]==1 直接 i++。

方法二（两次双指针）：第一遍把所有 0 换到前面；第二遍从当前 ptr 位置开始把所有 1 换到 0 的后面；剩下的自然就是 2。逻辑更稳健几乎不会写错。

void sortColors(int[] nums) {
    int p0 = 0, p2 = nums.length - 1, i = 0;
    while (i <= p2) {
        if (nums[i] == 0) { swap(nums, i++, p0++); }            // 换过来一定是 1
        else if (nums[i] == 2) { swap(nums, i, p2--); }         // i 不动，换回来的需再判
        else i++;
    }
}
void swap(int[] a, int x, int y) { int t = a[x]; a[x] = a[y]; a[y] = t; }
易错：为什么遇到 0 之后 i++ 而遇到 2 之后不加？因为 p0 交换过来的数一定是 1（i 已扫描过前面区域），而 p2 交换过来的数可能是任何值（可能是 0）需要原地再次判断。

15.4 下一个排列（L31）

整数数组表示一个排列，原地修改为字典序中的下一个更大排列，若不存在则变为最小排列（升序）。

核心：从右向左找第一个满足 nums[i]<nums[i+1] 的位置 i；找不到说明整个数组降序直接反转整个数组；找到了再从右向左找第一个大于 nums[i] 的位置 j；交换 nums[i] 和 nums[j]；反转 i+1 到末尾使后缀变成升序。

void nextPermutation(int[] nums) {
    int n = nums.length, i = n - 2;
    while (i >= 0 && nums[i] >= nums[i + 1]) i--;     // 找第一个升序对
    if (i >= 0) {
        int j = n - 1;
        while (nums[j] <= nums[i]) j--;                // 找右侧刚好大于 nums[i] 的
        swap(nums, i, j);
    }
    reverse(nums, i + 1, n - 1);
}
void reverse(int[] a, int l, int r) { while (l < r) { int t = a[l]; a[l++] = a[r]; a[r--] = t; } }
易错：后缀原本是降序交换后反转即可得到最小后缀；要从右往左找 j 这样能找到刚好大一点的数字；必须原地修改。

15.5 寻找重复数（L287）

包含 n+1 个整数的数组，每个整数都在 [1,n] 范围内，只有一个重复数字但可能出现多次，找出它，不能修改数组，额外空间 O(1)。

核心（快慢指针）：把数组看成链表，下标 i 指向 nums[i]；因为有重复数字所以一定会形成环；慢指针每次走一步 slow=nums[slow]；快指针每次走两步 fast=nums[nums[fast]]；第一次相遇后把一个指针放回起点；两个指针每次都走一步，再次相遇的位置就是重复数字。

int findDuplicate(int[] nums) {
    int slow = nums[0], fast = nums[nums[0]];
    while (slow != fast) { slow = nums[slow]; fast = nums[nums[fast]]; }  // 找环内相遇点
    slow = 0;
    while (slow != fast) { slow = nums[slow]; fast = nums[fast]; }        // 同速找入环点
    return slow;
}
这是环形链表 II 的思想迁移：把「数组中的重复数字」转化为「链表中的入环点」。
易错：不能修改数组所以原地哈希或排序不符合题目要求；起点通常从 0 开始因为 nums[0] 会进入 [1,n] 的链表区域。

附录、排序模板

这两个模板是算法面试的基本功，快速排序和归并排序的代码骨架必须熟练。

快速排序（Hoare 双指针分区）

public static void quickSort(int[] q, int l, int r) {
    if (l >= r) return;
    int i = l - 1, j = r + 1, x = q[l + (r - l) / 2];
    while (i < j) {
        do i++; while (q[i] < x);
        do j--; while (q[j] > x);
        if (i < j) { int t = q[i]; q[i] = q[j]; q[j] = t; }
    }
    quickSort(q, l, j);
    quickSort(q, j + 1, r);
}
易错：基准值 x 不一定被放到最终位置；递归边界必须配套写成 [l,j] 和 [j+1,r]；do while 配合初始值 i=l-1,j=r+1；比较条件用严格 <x 和 >x 大量重复元素时也能推进。

归并排序（自顶向下）

static int[] tmp;
public static void mergeSort(int[] q, int l, int r) {
    if (l >= r) return;
    int mid = l + (r - l) / 2;
    mergeSort(q, l, mid);
    mergeSort(q, mid + 1, r);
    int k = 0, i = l, j = mid + 1;
    while (i <= mid && j <= r) {
        if (q[i] <= q[j]) tmp[k++] = q[i++]; else tmp[k++] = q[j++];
    }
    while (i <= mid) tmp[k++] = q[i++];
    while (j <= r) tmp[k++] = q[j++];
    for (i = l, j = 0; i <= r; i++, j++) q[i] = tmp[j];
}
易错：合并时相等元素优先取左边 q[i]<=q[j] 可保证稳定性；临时数组 tmp 通常提前创建一次避免每层递归重复创建；时间复杂度稳定 O(n log n) 额外空间 O(n)。
